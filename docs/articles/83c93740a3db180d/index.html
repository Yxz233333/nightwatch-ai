OpenAI 宣布 GPT-5.5 已在 Codex 中上线，定位为面向复杂编码、计算机操作、知识工作和研究流程的前沿模型，并成为多数 Codex 任务的推荐选择。用户可在 CLI、IDE 扩展和 Codex 应用中选择该模型，未看到时需更新到最新版本。此次更新还为 Codex 应用加入浏览器操作、自动审批审查，并修复若干问题。

  • GPT-5.5 在 Codex 上线，适用于实现、重构、调试、测试与验证等任务。
  • Codex 应用新增浏览器操作，可点击渲染界面、复现视觉缺陷并验证本地修复。
  • 新增自动审批审查代理，并修复重复排队消息、模型设置回退等问题。
