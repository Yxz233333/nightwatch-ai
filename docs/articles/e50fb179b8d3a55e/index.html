Anthropic 发布第四份经济指数报告，引入“经济基元”指标，通过询问 Claude 关于匿名 Claude.ai 和第一方 API 转录的问题，从用户和AI技能、任务复杂度、自主性、成功率和用途五个维度衡量AI使用。报告基于2025年11月数据（Opus 4.5发布前），发现美国各州使用分布更均匀、任务集中度略有上升、计算机和数学任务仍占主导、API中办公行政支持任务份额上升等。

  • 引入五个经济基元：用户和AI技能、任务复杂度、自主性、成功率、用途（个人/教育/工作）。
  • Claude.ai 使用仍高度集中于少数任务，前十项O*NET任务占24%，修改软件错误单项占6%。
  • API客户中办公和行政支持任务份额从8月到11月上升3个百分点至13%，表明企业自动化后台工作流增加。
