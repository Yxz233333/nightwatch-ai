Hugging Face 介绍 TorchTPU 原生 PyTorch 后端

Hugging Face 介绍 TorchTPU，将 Google TPU 作为 PyTorch 原生设备接入 Transformers、Diffusers 和 Kernels。

具体内容

Hugging Face 介绍 TorchTPU，将 Google TPU 作为 PyTorch 原生设备接入 Transformers、Diffusers 和 Kernels。工作流支持 eager 执行、torch.compile 与分布式使用，减少为 TPU 维护独立代码分支的需要。原文提供安装和模型示例，性能取决于硬件、模型、编译配置及输入规模。

  • 通过 tpu 设备运行支持的模型，保留常规 PyTorch 编程方式。
  • Diffusers 示例区分 eager 与编译模式，首次编译与后续运行的开销不同。
  • 原文称运行 Hugging Face 模型不再必须通过 Optimum TPU，具体兼容性按文档确认。
