新版 ChatGPT 桌面应用整合 Chat、Work 与 Codex

官方发布信息显示，新版 ChatGPT 桌面应用面向 macOS 和 Windows 全球提供，把用于问答对话的 Chat、用于调研与交付成果的 Work、用于软件开发的 Codex 合并到同一应用。

具体内容

官方发布信息显示，新版 ChatGPT 桌面应用面向 macOS 和 Windows 全球提供，把用于问答对话的 Chat、用于调研与交付成果的 Work、用于软件开发的 Codex 合并到同一应用。经用户授权后，Work 可调用本地文件和桌面应用；内置浏览器可让 ChatGPT 从网站收集信息，并配合受支持的网页工具与文件。Codex 新增差异内联编辑、侧栏拉取请求审查、更快的计算机使用，以及单项目多仓库支持。原 Codex 应用用户按常规更新即可迁移，旧版 ChatGPT 桌面应用可能保留为 ChatGPT Classic。

  • 新版桌面应用面向 macOS 与 Windows 全球提供，整合 Chat、Work、Codex 三类能力。
  • Work 经用户授权可使用本地文件与桌面应用，内置浏览器可访问网站及受支持的网页工具。
  • Codex 新增差异内联编辑、侧栏 PR 审查、更快计算机使用和单项目多仓库支持。
