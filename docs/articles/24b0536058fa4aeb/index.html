Anthropic 经济指数报告：AI 采用的地理与企业不均衡

Anthropic 扩展经济指数，新增 Claude.ai 对话的地理分析及首次对企业 API 使用的考察。

具体内容

Anthropic 扩展经济指数，新增 Claude.ai 对话的地理分析及首次对企业 API 使用的考察。报告指出美国 40% 员工在工作中使用 AI，高于 2023 年的 20%。作者引入 Anthropic AI 使用指数（AUI）衡量各国 Claude.ai 使用相对工作年龄人口的过/欠代表程度，发现小国如以色列、新加坡领先，且人均 GDP 与 AUI 强相关。报告还首次分析企业 API 流量中的任务分布，并开源底层数据。作者认为早期采用集中可能加剧经济不平等。

  • 首次发布 150+ 国家及美国各州 Claude.ai 使用地理数据，并引入 AUI 指数。
  • 人均 GDP 与 AUI 强相关：全球 1% 更高 GDP 对应 0.7% 更高 AUI。
  • 首次分析企业 API 流量任务，开源数据支持独立研究。
