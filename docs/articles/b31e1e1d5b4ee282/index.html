Anthropic Labs推出Claude Design

Anthropic Labs发布新产品Claude Design，用户可与Claude协作生成设计稿、原型、幻灯片和一页纸材料等视觉作品。

具体内容

Anthropic Labs发布新产品Claude Design，用户可与Claude协作生成设计稿、原型、幻灯片和一页纸材料等视觉作品。该产品由作者称为最强视觉模型的Claude Opus 4.7驱动，以研究预览形式向Claude Pro、Max、Team和Enterprise订阅用户开放，并称当日逐步推送。发布还介绍了品牌设计系统自动应用、从提示词或文件导入、内联评论与滑块微调、组织内共享、导出至Canva/PDF/PPTX/HTML，以及打包交接给Claude Code等流程。

  • 由Claude Opus 4.7驱动，以研究预览向Pro、Max、Team、Enterprise订阅用户开放
  • 可读取代码库与设计文件自动建立团队设计系统并应用于每个项目
  • 支持内联评论、直接编辑与滑块微调，并可导出至Canva、PDF、PPTX或HTML
