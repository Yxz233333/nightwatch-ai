Claude 面向创意工作

具体内容

Anthropic 宣布为 Claude 增加一组连接器，使其可在 Adobe Creative Cloud、Blender、Autodesk Fusion、SketchUp 及音乐制作工具中配合创意工作流。原文称 Claude 不能替代品味与想象力，但可加速构思、承担重复性任务。Blender 连接器基于 MCP 构建，由 Blender 开发者制作，其他大模型也可使用；Anthropic 还向 Blender 项目作出一次性捐赠，并与多所院校合作开展创意计算课程。

  • 新增连接器覆盖 Adobe、Blender、Fusion、SketchUp 等工具
  • Blender 连接器基于 MCP，其他大模型亦可使用
  • 与多所院校合作，让学生和教师试用并反馈
