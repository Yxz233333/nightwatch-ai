Meta Superintelligence Labs 发布 Muse Spark 1.1，称其为 Muse Spark 的显著升级版，定位为面向智能体任务的多模态推理模型，在工具与计算机使用、编程和多模态理解方面有较大提升。官方称该模型支持 100 万 token 上下文，可编排多智能体系统，并能在 Meta AI 应用和 meta.ai 的“Thinking”模式中使用；同时开放 Meta Model API 公开预览。文中评测数据来自官方报告，本次整理未额外核验独立复现情况。

  • 官方称其为面向智能体任务的多模态推理模型，在工具使用、计算机操作和编程方面较前代提升明显。
  • 支持 100 万 token 上下文，可作为主智能体规划并分派子智能体，也能作为子智能体执行任务。
  • 随发布开放 Meta Model API 公开预览，模型已在 Meta AI 应用和 meta.ai 上线。
