具体内容

Codex CLI 0.65.0 版本更新公告，主要变化包括将 Codex Max 设为默认模型并修复 TUI 中异步套同步代码引发的崩溃；新增 /resume 斜杠命令并提升恢复会话性能；提示与工具提示改用 Markdown 渲染并加粗“Tip”标签；TUI 支持 Ctrl-P/N 导航、按屏幕行数限制 shell 输出、恢复 Windows 剪贴板图片粘贴；history.jsonl 可按 history.max_bytes 裁剪，默认忽略 __pycache__ 等目录。

  • Codex Max 成为默认模型，并修复 TUI 异步套同步导致的崩溃。
  • 新增 /resume 命令并优化恢复性能，便于继续此前工作。
  • history.jsonl 支持按 history.max_bytes 裁剪，默认忽略 __pycache__ 等目录。

CLI 稳定版本；桌面端功能另以对应公告为准。
