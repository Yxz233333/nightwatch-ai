具体内容

Codex CLI 0.143.0 发布，属 CLI 稳定版本更新。新功能包括：远程插件默认启用，并支持更丰富的目录行、npm 市场来源及可见的远程/本地版本；认证与 Responses API 流量可经 macOS 和 Windows 系统代理（含 PAC、WPAD）；新增 remote-control pair 命令生成手动配对码；新增 Amazon Bedrock GPT-5.6 Sol、Terra、Luna 模型并支持 max 推理强度；MCP 工具默认使用工具搜索。修复涉及 Windows ConPTY 输入、TUI 安全提示、执行服务器离线恢复等，并更新多个依赖以应对安全公告。

  • 远程插件默认启用，支持 npm 市场来源与版本可见
  • 新增系统代理路由、配对命令及 Bedrock GPT-5.6 系列模型支持
  • 修复 Windows ConPTY 输入与 MCP 启动状态等问题，并更新安全依赖

CLI 稳定版本；桌面端功能另以对应公告为准。
