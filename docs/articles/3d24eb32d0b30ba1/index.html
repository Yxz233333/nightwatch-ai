这是 Codex CLI 的 0.153 热修复版本，主要修复两项问题：一是 Astra 在捆绑模型选择器中的可见性，并在未显式配置模型时将其设为捆绑默认模型；二是调整 Astra 的指引，仅在会话中该工具可用时才使用异步提问。两项改动分别对应 #42874 与 #42878。

  • 修复 Astra 在捆绑模型选择器中的可见性，未显式配置时作为默认模型。
  • Astra 的异步提问指引改为仅在会话中工具可用时生效。
  • 两项均为 0.153 热修复，对应 #42874 与 #42878。

CLI 稳定版本；桌面端功能另以对应公告为准。
