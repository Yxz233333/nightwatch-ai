ChatGPT Ads 指定 Aleph 为44个市场广告主提供本地转售服务

OpenAI 宣布指定 Aleph 为 ChatGPT Ads 在44个国家的独家转售商，使当地品牌和代理机构可通过本地实体完成签约、以本币付款并获得本地销售支持、培训与投放服务。

具体内容

OpenAI 宣布指定 Aleph 为 ChatGPT Ads 在44个国家的独家转售商，使当地品牌和代理机构可通过本地实体完成签约、以本币付款并获得本地销售支持、培训与投放服务。覆盖范围包括拉美14国、欧洲与中亚16国、中东与非洲10国及亚太4个市场。OpenAI 表示该安排不改变广告主面向这些国家投放的能力，直接购买与全球技术合作伙伴渠道仍然保留，并称已有超过十万名营销人员在 ChatGPT 上投放广告。该44个市场指广告主所在地及本地转售支持，不等于44处用户市场都能访问ChatGPT或看见广告。

  • Aleph 成为 ChatGPT Ads 在44个国家的独家转售商，提供本地合同、本币开票与销售支持。
  • 覆盖拉美14国、欧洲与中亚16国、中东与非洲10国、亚太4个市场。
  • OpenAI 称不影响既有投放能力，Ads Manager 与全球技术合作伙伴渠道继续可用。
  • 原文脚注说明中国大陆和香港用户无法使用OpenAI模型及ChatGPT，亦不在当地提供ChatGPT Ads；转售支持不能等同产品在当地开放。
