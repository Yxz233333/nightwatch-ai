该版本更新日志显示，Codex CLI 0.103.0 的新功能包括：应用列表响应返回更丰富的应用详情，如 app_metadata、品牌信息与标签，使客户端无需额外请求即可渲染更完整的应用卡片；提交共同作者归属改用 Codex 管理的 prepare-commit-msg 钩子，并支持 command_attribution 覆盖配置。修复方面移除了 remote_models 功能开关，以避免其关闭时回退模型元数据。其余为依赖升级与工具链回退等维护工作。

  • 应用列表响应新增 app_metadata、品牌与标签等字段
  • 提交共同作者归属改用 prepare-commit-msg 钩子并支持配置覆盖
  • 移除 remote_models 功能开关以避免回退模型元数据

CLI 稳定版本；桌面端功能另以对应公告为准。
