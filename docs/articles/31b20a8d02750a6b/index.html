我们绘制一年AI网络威胁图谱的发现

Anthropic分析2025年3月至2026年3月间因恶意网络活动被封禁的832个账户，并将其映射到MITRE ATT&CK框架。

具体内容

Anthropic分析2025年3月至2026年3月间因恶意网络活动被封禁的832个账户，并将其映射到MITRE ATT&CK框架。报告发现，67.3%的账户使用AI编写恶意软件，6.5%用于横向移动；中高风险攻击者比例从33%升至56%。攻击者日益将AI用于攻击后期阶段，且传统风险指标（如技术数量）与风险等级相关性减弱。报告建议ATT&CK框架纳入AI智能体编排等行为。

  • 832个被封账户中67.3%使用AI编写恶意软件。
  • 中高风险攻击者占比从33%升至56%。
  • AI使用转向攻击后期阶段，传统风险指标失效。
