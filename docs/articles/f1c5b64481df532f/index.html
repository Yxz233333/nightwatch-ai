Microsoft Azure推出全球首个面向OpenAI的NVIDIA GB300 NVL72超级计算集群

Microsoft Azure宣布推出新的NDv6 GB300 VM系列，提供业界首个超级计算规模的NVIDIA GB300 NVL72系统生产集群，专为OpenAI最严苛的AI推理工作负载设计。

Microsoft Azure宣布推出新的NDv6 GB300 VM系列，提供业界首个超级计算规模的NVIDIA GB300 NVL72系统生产集群，专为OpenAI最严苛的AI推理工作负载设计。该集群包含超过4600块NVIDIA Blackwell Ultra GPU，通过NVIDIA Quantum-X800 InfiniBand网络平台连接。
