Codex CLI 0.105.0 发布

Codex CLI 发布 0.105.0 稳定版本，更新集中在终端界面与多智能体工作流。

具体内容

Codex CLI 发布 0.105.0 稳定版本，更新集中在终端界面与多智能体工作流。TUI 新增代码块与 diff 语法高亮、带实时预览的 /theme 主题选择器，以及按住空格录音转写的语音输入（仍在开发中，需在配置中开启）。多智能体方面支持从 CSV 批量派生任务并显示进度与预计时间，子智能体增加昵称与更清晰的审批提示。此外还修复了长链接换行、审批对话框请求 ID、Linux 沙箱 /dev 挂载等问题。

  • TUI 支持代码块与 diff 语法高亮，并新增带实时预览的 /theme 主题选择器。
  • 语音转写输入仍处开发阶段，需设置 features.voice_transcription = true 开启。
  • spawn_agents_on_csv 支持从 CSV 批量派生任务，并内置进度与预计时间显示。

CLI 稳定版本；桌面端功能另以对应公告为准。
