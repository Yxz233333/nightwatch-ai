官方发布记录显示，ChatGPT Work 的定时任务可通过 webhook 在受支持应用发生变化时触发，例如收到新 Gmail 邮件、Slack 频道消息或 GitHub 拉取请求变动，减少反复查看。用户还可分享任务，让他人查看并自定义指令、连接自己的应用并创建独立副本。Plus 和 Pro 用户可在网页、iOS 和 Android 上创建 webhook 触发任务；Free 用户最多创建三个活跃定时任务，且 Free 与 Go 用户不能创建 webhook 触发任务。

  • 定时任务可用 webhook 响应 Gmail、Slack 和 GitHub 变化
  • 分享后接收方可自定义并创建独立副本
  • Free 用户最多三个活跃任务，Free 与 Go 不支持 webhook 触发
