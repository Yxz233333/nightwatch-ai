GPT-5.1 系列模型退役

官方发布记录显示，自2026年3月11日起，GPT-5.1 Instant、GPT-5.1 Thinking 和 GPT-5.1 Pro 不再在 ChatGPT 中提供。

具体内容

官方发布记录显示，自2026年3月11日起，GPT-5.1 Instant、GPT-5.1 Thinking 和 GPT-5.1 Pro 不再在 ChatGPT 中提供。此前使用 GPT-5.1 的现有对话将自动继续在对应的当前模型上运行，即 GPT-5.3 Instant、GPT-5.4 Thinking 或 GPT-5.4 Pro。

  • 2026年3月11日起，GPT-5.1 Instant、Thinking 和 Pro 在 ChatGPT 中不再可用。
  • 使用 GPT-5.1 的现有对话自动迁移至对应的 GPT-5.3 Instant、GPT-5.4 Thinking 或 GPT-5.4 Pro。
  • 该退役安排仅涉及 ChatGPT 中的 GPT-5.1 模型。
