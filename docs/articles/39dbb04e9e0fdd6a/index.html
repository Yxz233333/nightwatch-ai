Codex CLI 0.158.0 为稳定版本更新，新增全屏 TUI 的选中即复制与右键粘贴配置，复制内容保留 Markdown 格式；支持连接需预注册 OAuth 客户端密钥的 MCP 服务器，并为 exec-server 直连 WebSocket 增加 bearer token 认证。图像生成与编辑可显式请求透明背景，编辑支持文件型会话图像；高权限命令的终端输入审批默认开启。另修复 Windows 与 Linux 沙箱、审批重试及 Mermaid 渲染等问题。

  • 全屏 TUI 支持选中即复制与右键粘贴，复制内容保留 Markdown 格式
  • 支持需预注册 OAuth 客户端密钥的 MCP 服务器，并新增 WebSocket bearer token 认证
  • 高权限命令终端输入审批默认开启，修复 Windows/Linux 沙箱与 Mermaid 渲染问题

CLI 稳定版本；桌面端功能另以对应公告为准。
