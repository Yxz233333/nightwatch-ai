Codex（Plus/Pro）更新——推出 GPT-5-Codex

OpenAI 为 Codex 添加 GPT-5-codex，这是针对 Codex 中代理式编码优化的 GPT-5 变体。

具体内容

OpenAI 为 Codex 添加 GPT-5-codex，这是针对 Codex 中代理式编码优化的 GPT-5 变体。它可在所有使用 Codex 的地方使用：云任务和代码审查默认使用，本地工作流可通过 Codex CLI 和 IDE 扩展选择。官方建议在 Codex 或类似环境中用于编码工作，通用非编码任务使用 GPT-5。注意 GPT-5-Codex 目前不支持 ChatGPT 或 API。

  • GPT-5-codex 是针对 Codex 代理式编码优化的 GPT-5 变体。
  • 云任务和代码审查默认使用，本地可通过 CLI 和 IDE 扩展选择。
  • 目前不支持 ChatGPT 或 API，仅限 Codex 环境。
