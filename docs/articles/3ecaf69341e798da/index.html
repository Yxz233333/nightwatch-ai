Terminal X 借助 GPT-6.1 使判断与资深投资人一致率达 88.6%

OpenAI 官方发布案例称，金融科技初创公司 Terminal X 的 Capital Memory 系统将投资机构的决策逻辑编码进自有智能体，并用 Eval Agent 按 54 项标准评分。

具体内容

OpenAI 官方发布案例称，金融科技初创公司 Terminal X 的 Capital Memory 系统将投资机构的决策逻辑编码进自有智能体，并用 Eval Agent 按 54 项标准评分。稿件表示，使用 GPT-6.1 Sol 后，Eval Agent 对偏离基金授权范围建议的检出率比次优模型高约 25%，与人工评审的一致率提升 220 个基点，单次查询成本低约 30%，某客户年化节省 240 万美元。这些是官方客户案例的报告结果，不能等同于投资收益或普遍效果保证。

  • Eval Agent 依据 54 项标准评分，GPT-6.1 Sol 对偏离基金授权建议的检出率比次优模型高约 25%
  • 官方称与人工评审的一致率提升 220 个基点，单次查询成本低约 30%
  • 系统部署在客户本地或自有云，由前金融从业工程师协助编码投资逻辑
