Cognizant 与 Anthropic 扩大合作，将 Claude 引入企业客户

Anthropic 宣布扩大与技术服务公司 Cognizant 的合作。

具体内容

Anthropic 宣布扩大与技术服务公司 Cognizant 的合作。Cognizant 将在其为制造、生命科学、保险等行业客户构建和运行的系统中使用 Claude，并把 Claude 嵌入自身业务与工程平台，包括 Flowsource、Neuro AI Engineering 和 Neuro IT Ops。Cognizant 已有超过 3 万名员工完成 Claude 培训，并成为 Claude 合作伙伴网络中的全球首要合作伙伴。双方称，将 AI 集成到大型企业需要行业知识、现有系统理解和规则意识，Cognizant 可提供这些领域背景与工程交付规模。

  • Cognizant 将 Claude 嵌入 Flowsource、Neuro AI Engineering 和 Neuro IT Ops 等平台。
  • 超过 3 万名 Cognizant 员工已完成 Claude 培训。
  • Cognizant 成为 Claude 合作伙伴网络全球首要合作伙伴。
