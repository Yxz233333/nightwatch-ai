OpenAI发布文章介绍其模型在芯片设计中的进展：早期GPT-4o已参与自研推理芯片Jalapeño的计算模块优化，团队估计向量单元标准单元面积减少约13%、矩阵单元约10%，并在流片中完成硅验证。与AMD合作中，模型通过改写SystemVerilog RTL在旗舰GPU IP上相对高度优化基线取得最高14%的PPA提升，AMD已将部分改动纳入送产设计。文章还用两款开源32位RISC-V核评测各代模型的吞吐优化与按规格设计能力，并宣布与Synopsys合作训练模型使用EDA工具。

  • GPT-4o参与Jalapeño设计，团队估计向量单元面积减约13%、矩阵单元约10%，并完成硅验证。
  • 与AMD合作中模型改写RTL，在旗舰GPU IP上相对高度优化基线最高提升14% PPA。
  • 在PicoRV32与Ibex两款RISC-V核评测中，GPT-6.2 Astra在约11.2万token预算下平均得分最高。
