你的专家有搭档：HOPE 让它们保持在一起

该文介绍亚马逊团队提出的 HOPE（高阶专家剪枝）方法，用于压缩混合专家（MoE）语言模型。

具体内容

该文介绍亚马逊团队提出的 HOPE（高阶专家剪枝）方法，用于压缩混合专家（MoE）语言模型。作者指出，MoE 推理时所有专家 MLP 都占内存，但每个 token 只激活少数专家；现有剪枝方法按单个专家独立打分，忽略了专家之间稳定的协作关系。HOPE 用二阶方法在标定集上构建专家两两交互矩阵，求解二次规划选出剪枝集合。作者声称在 50% 剪枝率下平均排名最优，在该剪枝率下，相对次优剪枝方法的智能体编程得分最高增加6.1%。

  • HOPE 构建专家两两交互的 F 矩阵，用二次规划选剪枝集合，而非独立打分。
  • 作者称 50% 剪枝时平均排名 1.58，优于次优方法 REAP 的 2.42。
  • F 矩阵对角线几乎复现 REAP 排名（Spearman ρ=0.988），增益来自非对角交互项。

依据原始发布整理；研究和厂商测试不等于独立验证。
