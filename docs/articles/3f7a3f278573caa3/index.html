预览 Ultrafast 模式：GPT-5.6 Sol 速度最高提升至 14 倍

OpenAI 官方发布记录显示，其正在预览一项名为 Ultrafast 的 API 服务层级，可将 GPT-5.6 Sol 的运行速度提升至原来的 14 倍。

具体内容

OpenAI 官方发布记录显示，其正在预览一项名为 Ultrafast 的 API 服务层级，可将 GPT-5.6 Sol 的运行速度提升至原来的 14 倍。该服务由 Cerebras 提供算力支持，输出速度最高可达每秒 750 个 token。原文未说明具体开放范围、适用条件与限制，这些信息需以官方原始发布为准。

  • Ultrafast 是 OpenAI 新增的 API 服务层级，用于加速 GPT-5.6 Sol。
  • 官方称速度最高提升至 14 倍，输出可达每秒 750 个 token。
  • 该服务由 Cerebras 提供算力支持。
