Codex CLI 0.169.0 正式发布，增强按需启用的终端工作区、任务搜索、自定义模型提供商和诊断保存，并修复信任目录、计划交接及Windows沙箱问题。

  • 可选终端工作区支持多个侧聊标签、重启后恢复本地侧聊；命令中心可按名称、提示或工作目录搜索旧任务。
  • 全屏记录可折叠已完成活动；终端支持配置自定义提供商，并可用Ctrl+S本地保存诊断ZIP。
  • macOS/Linux可选Cloud连接支持图片、模型与推理强度选择、归档及恢复；这些可选能力不表示所有平台默认开启。
  • 修复不可信目录中的项目配置与MCP启用边界、批准计划传递、Windows路径及工作目录沙箱处理。

已发布正式版；部分功能需按说明启用。
