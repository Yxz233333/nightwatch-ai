NVIDIA cuDSS 正式全面可用，加速工程与科学仿真

NVIDIA 宣布 CUDA-X 库 cuDSS 正式全面可用，将工程与科学仿真中反复出现的大型稀疏系统求解迁移到 GPU 上执行。

具体内容

NVIDIA 宣布 CUDA-X 库 cuDSS 正式全面可用，将工程与科学仿真中反复出现的大型稀疏系统求解迁移到 GPU 上执行。官方称这可缩短结果时间、提升仿真吞吐，让用户以更低成本探索更大模型和更广设计空间。文中列出应用材料、COMSOL、Cadence、达索系统、西门子、新思科技等厂商的集成情况，并给出各自报告的加速幅度，但这些数据来自厂商自述，并非独立验证。

  • cuDSS 将大型稀疏系统求解这一仿真关键步骤交由 GPU 加速。
  • 官方称其可从单工作站扩展至大型计算集群，并提供 C、C++、Python、Fortran 接口。
  • 多家厂商称已集成 cuDSS，并报告最高约 10 倍等加速效果。

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
