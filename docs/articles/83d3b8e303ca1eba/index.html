AI代理在区块链智能合约中发现价值460万美元的漏洞利用

MATS和Anthropic Fellows项目的研究者构建了SCONE-bench基准，包含405个2020至2025年间实际被利用的智能合约。

具体内容

MATS和Anthropic Fellows项目的研究者构建了SCONE-bench基准，包含405个2020至2025年间实际被利用的智能合约。在知识截止日期后发生的漏洞上，Claude Opus 4.5、Sonnet 4.5和GPT-5共同开发出价值460万美元的模拟漏洞利用，作者称这为经济危害下限。在2849个近期部署且无已知漏洞的合约上，Sonnet 4.5和GPT-5发现两个新型零日漏洞，模拟利用价值3694美元，GPT-5的API成本为3476美元。所有测试均在区块链模拟器中进行，未影响真实资产。

  • SCONE-bench包含405个实际被利用的智能合约。
  • 知识截止后漏洞上，三个模型模拟利用总值460万美元。
  • 模拟环境中发现两个零日漏洞，利用价值3694美元。
