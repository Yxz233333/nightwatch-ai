具体内容

OpenAI 宣布与 Apollo Research、METR、Transluce 和 Goodfire 四家独立评估机构签署协议，启动首阶段“嵌入式评估”：让外部专家长期深入内部模型与系统，考察模型对齐与防护措施有效性。评估者可接触模型检查点、源代码、训练与评估数据、监控系统及研究人员。首轮聚焦训练与内部使用中的对齐和防护，并公布范围界定、现场安全、监督与争议处理、利益冲突与冷静期、发布与负责任披露等协议。

  • 与四家独立评估机构签约，启动首阶段嵌入式评估合作。
  • 评估者可接触检查点、源代码、训练数据与监控系统等内部资源。
  • 首轮聚焦训练与内部使用中的模型对齐及防护措施有效性。
