具体内容

Anthropic在网页版Claude Code中内置Claude Code Security，以有限研究预览形式向Enterprise和Team客户开放，开源仓库维护者可申请加速访问。该功能不依赖规则匹配，而是像人类安全研究员一样阅读并推理代码，追踪数据流动，寻找业务逻辑缺陷和访问控制错误等复杂漏洞。每个发现先经多阶段验证以过滤误报，并标注严重程度和置信度，补丁须经人工批准才会应用。官方称用Claude Opus 4.6在生产开源代码库中发现500多个漏洞，正与维护者协调分类和披露。
