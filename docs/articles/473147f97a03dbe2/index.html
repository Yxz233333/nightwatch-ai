Google Cloud A5X 与 NVIDIA Vera Rubin 基础设施计划下月正式可用

Google Cloud 与 NVIDIA 宣布，由 NVIDIA Vera Rubin NVL72 加速的 A5X 实例计划于2026年11月正式可用，并计划扩展至欧洲，为训练、推理和大规模强化学习提供集成平台。

具体内容

Google Cloud 与 NVIDIA 宣布，由 NVIDIA Vera Rubin NVL72 加速的 A5X 实例计划于2026年11月正式可用，并计划扩展至欧洲，为训练、推理和大规模强化学习提供集成平台。稿件称 A5X 整合 Vera Rubin NVL72、ConnectX-9 SuperNICs、Google Cloud Virgo 网络与第四代液冷技术，并计划在多个站点扩展到最多 96 万块 Rubin GPU。首批客户 Ineffable Intelligence 用于大规模强化学习，WPP 则演示了创意智能体参考架构。

  • A5X 实例整合 Vera Rubin NVL72、ConnectX-9 SuperNICs、Virgo 网络与第四代液冷技术。
  • Google Cloud 计划将基于 Vera Rubin 的基础设施扩展至多站点最多 96 万块 Rubin GPU。
  • Ineffable Intelligence 为首批客户，用于大规模强化学习与“超级学习者”系统。

官方预告：A5X实例计划下月正式可用，欧洲开放范围另有扩展计划；不可视为已全面上线。
