具体内容

Anthropic 发布第四份经济指数报告，引入“经济基元”以追踪 Claude 的经济影响，包括任务复杂度、技能水平、用途、AI自主性和成功率。报告基于2025年11月样本（主要使用 Claude Sonnet 4.5），发现更复杂任务被加速最多，Claude 在需要大学学位的任务上成功率为66%，低于高中以下任务的70%；不同经济发展阶段国家使用目的不同；调整成功率后部分职业受影响更大。

  • 经济基元包括任务复杂度、技能水平、用途、AI自主性和成功率，通过询问 Claude 关于对话的问题得出。
  • 更复杂任务被加速最多：Claude.ai 上需高中教育任务加速9倍，需大学学位任务加速12倍。
  • Claude 在需大学学位任务上成功率为66%，低于高中以下任务的70%；调整成功率后数据录入员和放射科医生等职业受影响更大。
