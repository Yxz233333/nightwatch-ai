ChatGPT iOS 版 1.2026.146 更新

具体内容

这是 ChatGPT iOS 客户端 1.2026.146 版本的更新说明，主要围绕 Codex 功能与连接能力。新增可选的面容 ID 或密码锁保护 Codex；新增设置页，可选择 Queue 或 Steer 作为默认追问行为，并切换代码差异的自动换行；支持通过 SSH 连接 Windows 机器。此外新增 /side 命令，可在提出初始问题时开启侧边对话，并改进追问提示、Codex 主屏和变更文件查看，修复重连、归档会话、加载任务及连接主机等问题。

  • Codex 新增可选面容 ID 或密码锁，提升本地访问保护。
  • 新增设置页，可选 Queue 或 Steer 默认追问行为并切换代码差异换行。
  • 支持通过 SSH 连接 Windows 机器，并新增 /side 侧边对话命令。
