ChatGPT桌面应用体验更新

OpenAI更新ChatGPT桌面应用，已在macOS和Windows面向所有套餐上线。

具体内容

OpenAI更新ChatGPT桌面应用，已在macOS和Windows面向所有套餐上线。新版加入全局切换器，可在ChatGPT与Codex之间选择；在ChatGPT内可切换Chat（快速问答）与Work（端到端完成任务）。Chat与Work对话统一显示在Recents中，可排序、筛选和置顶；现有Projects进入桌面应用，可在项目内发起对话或基于项目上下文开启Work线程。云端Work对话可在网页、移动端和桌面端同步，本地对话仍留在本机；Codex保持独立视图，工作流与历史不变。

  • 全局切换器区分ChatGPT与Codex，Chat内再分Chat与Work
  • Chat与Work对话统一进入Recents，可排序、筛选、置顶
  • 云端Work对话跨网页、移动端和桌面端同步，本地对话留在本机
