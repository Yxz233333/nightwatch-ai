用AI更深入地感知宇宙

稿件提出一种名为Deep Loop Shaping的AI控制方法，用于改善引力波天文台的反馈控制。

具体内容

稿件提出一种名为Deep Loop Shaping的AI控制方法，用于改善引力波天文台的反馈控制。作者称，该方法与LIGO和GSSI合作开发，并在路易斯安那州利文斯顿天文台验证，将LIGO最不稳定反馈环路的噪声降低30至100倍，提升干涉仪镜面稳定性。摘要表示，若应用于全部镜面控制环路，有望帮助天文学家每年探测更多事件；未来也可用于振动抑制、噪声消除等工程问题。

  • Deep Loop Shaping采用强化学习与频域奖励，降低控制噪声。
  • 作者称在LIGO利文斯顿实测中噪声降低30至100倍。
  • 摘要表示应用于全部镜面环路或可每年探测数百更多事件。
