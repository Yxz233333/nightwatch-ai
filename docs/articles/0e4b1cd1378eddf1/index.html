Codex CLI 0.85.0 版本发布，新增应用服务器v2将协作工具调用作为项目事件发出、协作工具支持代理角色预设和中断能力、/models元数据包含升级迁移说明；修复Linux沙箱在用户命名空间不可用时回退到仅Landlock并提前设置no_new_privs、codex resume --last尊重当前工作目录、stdin提示解码处理BOM/UTF-16等问题。

  • 应用服务器v2将协作工具调用作为项目事件发出，客户端可实时渲染代理协调。
  • 协作工具增强：spawn_agent接受代理角色预设，send_input可选中断运行中的代理。
  • 修复Linux沙箱回退逻辑，在用户命名空间不可用时仅使用Landlock并提前设置no_new_privs。

CLI 稳定版本；桌面端功能另以对应公告为准。
