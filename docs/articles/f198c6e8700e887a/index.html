Codex CLI 0.160.1 发布

该补丁版本更新日志显示，Codex CLI 0.160.1 主要修复一个问题：在使用显式配置的远程环境变量启动远程 stdio MCP 服务器时，保留 SYSTEMROOT、TEMP 和 TMP，使 Unix 主机能够保留 Windows 执行器的启动环境。

该补丁版本更新日志显示，Codex CLI 0.160.1 主要修复一个问题：在使用显式配置的远程环境变量启动远程 stdio MCP 服务器时，保留 SYSTEMROOT、TEMP 和 TMP，使 Unix 主机能够保留 Windows 执行器的启动环境。该修复已回移植到 0.160 分支。

  • 修复远程 stdio MCP 服务器启动时的环境变量保留问题
  • 保留 SYSTEMROOT、TEMP、TMP 三个变量
  • 相关修复已回移植到 0.160 分支

CLI 稳定版本；桌面端功能另以对应公告为准。
