文章介绍 Claude Code 的多项升级：原生 VS Code 扩展（测试版）、终端界面 2.0，以及用于自主操作的检查点功能。原文称在 Sonnet 4.5 驱动下，Claude Code 可在终端与 IDE 中处理更长、更复杂的开发任务。检查点会在每次更改前自动保存代码状态，用户可回退到先前版本，并选择恢复代码、对话或两者。原文还提到 Claude Agent SDK 支持子智能体与钩子，便于定制工作流。

  • 推出原生 VS Code 扩展测试版，可在 IDE 侧栏查看实时差异。
  • 检查点自动保存代码状态，支持双击 Esc 或 /rewind 回退。
  • Claude Agent SDK 开放核心工具与权限框架，支持子智能体与钩子。
