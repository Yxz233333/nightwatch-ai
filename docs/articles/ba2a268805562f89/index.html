推出Anthropic Interviewer：1250名专业人士谈与AI共事

该研究发布介绍新工具Anthropic Interviewer，由Claude驱动，可自动开展大规模访谈并把结果交给人类研究员分析。

具体内容

该研究发布介绍新工具Anthropic Interviewer，由Claude驱动，可自动开展大规模访谈并把结果交给人类研究员分析。作者用它对1250名专业人士进行测试访谈，包括1000名一般职业者、125名创意工作者和125名科学家，并公开经同意的访谈数据。摘要表示，一般样本中86%称AI节省时间、65%表示满意；作者强调这是工具测试，数据为初步发现。

  • Anthropic Interviewer由Claude驱动，自动完成规划、访谈与分析
  • 测试访谈1250名专业人士，含一般职业、创意与科学三个样本
  • 作者称一般样本86%认为AI节省时间，65%表示满意
