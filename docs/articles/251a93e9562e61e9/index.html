具体内容

IBM Research 介绍 ALTK-Evolve，从智能体在训练任务中的成功与失败轨迹提炼行为准则，附加到系统提示中，不更新模型权重。作者在 τ²-bench 零售与航空客服任务上测试不同数量的准则，并报告准确率和多次尝试一致性的提升。较长提示增加输入 token 成本，最佳准则数量随领域而变。

  • 以现有 ReAct 框架和标准模型执行任务，学习内容作为提示中的操作手册。
  • Pass^4 衡量四次尝试均成功的任务比例，与平均准确率不同。
  • 榜单比较采用10月12日快照，不能将发布时间的宣传标题理解为持续实时排名。
