ChatGPT开始推出个人财务体验，美国Pro用户可安全连接支持的金融账户，查看资金流向仪表板，并基于财务背景提问。该功能在网页和iOS上可用，可查看支出、账单、订阅、净资产和投资信息，并通过Plaid连接账户。ChatGPT可帮助理解和规划，但不能转移资金、支付账单、进行交易、报税或充当财务顾问。

  • 美国Pro用户可连接金融账户查看财务仪表板
  • 支持支出、账单、订阅、净资产和投资信息查看
  • ChatGPT不能执行资金转移或提供财务建议
