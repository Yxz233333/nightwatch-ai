具体内容

Codex CLI 0.30.0 版本发布，包含一项破坏性变更：停止自动加载项目 .env 文件。更新还涉及安全行为改进（不存储请求、取消待处理 OAuth 登录以释放端口）、核心基础设施优化（引入 rollout 策略、共享 HTTP 客户端）、TUI/UX 修复以及开发者体验和文档更新。

  • 破坏性变更：不再自动加载项目 .env 文件。
  • 安全改进：不存储请求，取消待处理 OAuth 登录释放端口。
  • 核心更新：引入 rollout 策略和共享 HTTP 客户端。

CLI 稳定版本；桌面端功能另以对应公告为准。
