Uber携手OpenAI向全体员工部署ChatGPT Work

OpenAI官方发布消息称，Uber宣布在公司范围内推广ChatGPT Work，这是一款在ChatGPT Enterprise内帮助员工处理多种任务的智能体。

具体内容

OpenAI官方发布消息称，Uber宣布在公司范围内推广ChatGPT Work，这是一款在ChatGPT Enterprise内帮助员工处理多种任务的智能体。此次推广覆盖Uber全球超过3万名员工，从此前1000名员工的试点扩展而来，成为Uber首个面向知识工作的全公司级智能体平台部署。该智能体可连接Google Drive、Gmail、Google日历和Slack等日常工具，用于调研信息、准备会议简报、制作演示、分析数据和完成跨应用工作流。Uber还将获得OpenAI前沿模型组合，其中GPT-6.1 Sol将作为默认能力部署。

  • 推广覆盖Uber全球逾3万名员工，由此前1000人试点扩展至全公司。
  • ChatGPT Work可连接Google Drive、Gmail、日历和Slack，支持跨应用完成工作流。
  • GPT-6.1 Sol将作为ChatGPT Work默认能力部署，兼顾前沿性能与成本效率。

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
