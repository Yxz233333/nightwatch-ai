Codex CLI 0.154.0 发布

Codex CLI 发布 0.154.0 稳定版本。

具体内容

Codex CLI 发布 0.154.0 稳定版本。更新日志显示，模型选择器和 Amazon Bedrock 目录新增 GPT-6-Astra；实验性 worktree 支持可为新会话或分叉会话创建隔离检出并浏览恢复；用户可在 Codex 继续工作时以内联方式回答问题；Windows 会话可共享后台 Codex 服务器并支持守护进程生命周期命令和托管更新；Vim 编辑新增 R 替换模式。此外还包含插件工具刷新、MCP OAuth 令牌刷新协调、启动前工作区信任检查等修复，以及文档和杂项更新。

  • 模型选择器和 Amazon Bedrock 目录新增 GPT-6-Astra。
  • 实验性 worktree 支持隔离检出，Windows 会话可共享后台服务器。
  • Vim 编辑新增 R 替换模式，并修复插件、MCP 与启动信任等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
