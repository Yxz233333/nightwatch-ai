官方发布记录显示，codex mcp-server 命令与独立的 codex-mcp-server 二进制在 2026 年 8 月 24 日被弃用后现已移除。

具体内容

官方发布记录显示，codex mcp-server 命令与独立的 codex-mcp-server 二进制在 2026 年 8 月 24 日被弃用后现已移除。依赖这两个命令启动的集成需在升级 Codex 前完成调整，改用 Codex app server 接入；但 app-server 命令仍属实验性，官方明确不支持生产负载。Codex 仍可通过 codex mcp 连接外部 MCP 服务器。

  • codex mcp-server 命令与独立二进制在弃用后被移除，需在升级前更新集成。
  • 官方建议改用 Codex app server，但该命令为实验性，不支持生产负载。
  • Codex 仍支持通过 codex mcp 连接外部 MCP 服务器。
