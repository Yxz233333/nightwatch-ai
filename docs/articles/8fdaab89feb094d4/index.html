Codex CLI 0.48.0 发布

Codex CLI 0.48.0 是命令行工具的稳定版本更新，带来多项功能改进。

具体内容

Codex CLI 0.48.0 是命令行工具的稳定版本更新，带来多项功能改进。新增 --add-dir 参数以添加额外工作目录；MCP 方面有多项增强：stdio 服务器改用基于官方 rust MCP SDK 的新客户端、可指定 cwd、所有服务器可配置启用或禁用工具、Streamable HTTP 服务器在登录时可指定 scopes、改进启动错误信息与工具调用指令遵循。此外新增 forced_login_method 和 forced_chatgpt_workspace_id 配置选项，可配合托管配置为企业提供更多控制。

  • 新增 --add-dir 参数，允许添加额外可写工作目录。
  • MCP 改进包括新 rust SDK 客户端、工具启停配置和 scopes 指定。
  • 新增强制登录方法与工作区 ID 配置，增强企业管控。

CLI 稳定版本；桌面端功能另以对应公告为准。
