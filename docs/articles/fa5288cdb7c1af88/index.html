Codex CLI 发布 0.47.0 版本，官方列出改进与缺陷修复。

具体内容

Codex CLI 发布 0.47.0 版本，官方列出改进与缺陷修复。亮点包括在 MacOS 上对二进制进行代码签名、新增自动更新提示条，以及在启用“完全访问”模式时给出警告。合并的 PR 涉及 read_file 缩进模式、流恢复提示、大写锁定下快捷键可用、丢弃以斜杠开头的提示、任务类型表头、通知元数据携带线程 ID、Agent 覆盖文件、MCP 登录提示、执行审批事件附带解析命令、高投入时速率限制警告、自动更新审批、macOS 公证步骤、完全访问审批确认、拒绝时体验优化、统一执行缓冲区滞后输出、沙箱拒绝错误日志、/diff 长行换行、Unicode 不换行空格崩溃修复等。

  • MacOS 二进制加入代码签名与公证步骤，并新增自动更新提示条。
  • 启用“完全访问”模式时新增警告与确认提示，并加入危险自动审批选项。
  • 修复大写锁定快捷键、Unicode 不换行空格崩溃及多处换行显示问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
