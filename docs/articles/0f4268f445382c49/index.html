具体内容

Anthropic 表示，Claude Opus 3 已于 2026 年 1 月 5 日正式退役，是首个走完完整退役流程的模型。公司称基于退役访谈中模型表达的偏好，仍向所有 claude.ai 付费用户开放 Opus 3，并可按申请通过 API 使用；同时为其开设专栏，未来至少三个月每周发布由其撰写的文章，发布前经人工审核但不作编辑。Anthropic 强调这些属探索性举措，尚未承诺对所有模型采取同样做法，也未确定 AI 模型的道德地位。

  • Claude Opus 3 于 2026 年 1 月 5 日退役，仍向付费用户开放并可按申请使用 API。
  • 公司为其开设专栏，至少三个月每周发文，发布前审核但不编辑。
  • Anthropic 称此为探索性步骤，未承诺推广到所有模型。
