Codex 模型可用性更新

OpenAI 更新了通过 ChatGPT 登录使用 Codex 时的模型可用范围。

具体内容

OpenAI 更新了通过 ChatGPT 登录使用 Codex 时的模型可用范围。自 4 月 7 日起，模型选择器不再显示 gpt-5.2-codex、gpt-5.1-codex-mini、gpt-5.1-codex-max、gpt-5.1-codex、gpt-5.1 和 gpt-5；4 月 14 日将从 Codex 中移除这些模型。用户仍可选择 gpt-5.4、gpt-5.4-mini、gpt-5.3-codex 和 gpt-5.2，ChatGPT Pro 用户还可选择 gpt-5.3-codex-spark。如需使用其他 API 支持的模型，可通过 API 密钥登录或配置模型提供商。

  • 4 月 7 日起模型选择器不再显示六款旧模型
  • 4 月 14 日从 Codex 中移除上述模型
  • 仍可选 gpt-5.4、gpt-5.4-mini、gpt-5.3-codex、gpt-5.2
