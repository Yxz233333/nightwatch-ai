OpenAI与希腊政府启动“OpenAI for Greece”

OpenAI与希腊政府宣布合作推出“OpenAI for Greece”计划，将ChatGPT Edu引入中学课堂，支持负责任的AI学习。

具体内容

OpenAI与希腊政府宣布合作推出“OpenAI for Greece”计划，将ChatGPT Edu引入中学课堂，支持负责任的AI学习。官方摘要称，该合作旨在提升AI素养、扶持本地初创企业并推动国家经济增长。材料未披露具体覆盖学校数量、实施时间表或评估方式，推出范围与限制需以原始发布为准。

  • 合作将ChatGPT Edu引入希腊中学，支持负责任的AI学习。
  • 官方称目标包括提升AI素养、扶持本地初创企业。
  • 计划还声称将推动国家经济增长，具体细节未披露。
