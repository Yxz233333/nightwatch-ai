具体内容

Codex for Students面向美国和加拿大通过验证的大学生开放。符合条件的学生可领取100美元ChatGPT额度，即2500点额度，用于在ChatGPT Free、Go、Plus和Pro所含限额之外继续使用Codex。学生需登录指定页面，用学校邮箱通过SheerID完成学生验证，额度会自动发放到个人工作区，可用于Codex，但不属于API额度，自发放日起12个月后过期。

  • 可领100美元即2500点ChatGPT额度，非API额度
  • 额度自动发放至个人工作区，12个月后过期
