Codex CLI 0.107.0 发布说明列出多项新功能与修复：可将线程分叉为子代理，实时语音会话支持选择并记住麦克风与扬声器设备，自定义工具可返回图像等多模态输出，应用服务器暴露更丰富的模型可用性与升级元数据，记忆功能可配置并新增清除记忆的调试命令。修复涉及线程恢复时重放待处理请求、thread/start 非阻塞、终端重复输出、大段粘贴占位符及 MCP OAuth 资源参数等。

  • 支持将线程分叉为子代理，便于在当前对话内分支工作。
  • 实时语音会话可选择并持久化麦克风与扬声器设备。
  • 自定义工具可返回图像等结构化多模态输出，不再限于纯文本。

CLI 稳定版本；桌面端功能另以对应公告为准。
