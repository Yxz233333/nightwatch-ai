ChatGPT Work 现可在需登录的网站上完成任务

官方发布说明称，ChatGPT Work 在网页端和移动端的浏览器可协助完成部分需要登录的网站任务：用户提出任务后，若网站支持认证，ChatGPT 会弹出登录界面供用户安全输入凭据，可能还需输入安全验证码；登录后它继续执行任务，会话可能保持登录以便后续任务。
