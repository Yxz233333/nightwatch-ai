DevRev 借助 GPT-6.1 Sol 实现自主自助服务

OpenAI 官方发布的企业案例称，DevRev 使用 GPT-6.1 Sol 驱动其 Computer 与 Operator 两款智能体，面向服务与运营团队处理客户及员工请求。

具体内容

OpenAI 官方发布的企业案例称，DevRev 使用 GPT-6.1 Sol 驱动其 Computer 与 Operator 两款智能体，面向服务与运营团队处理客户及员工请求。据 DevRev 首席技术官 Ahmed Bashir 介绍，模型负责推理、规划与工具选择，公司自建的上下文与权限框架控制智能体可执行的动作，并强调动作可逆、答案可溯源。DevRev 还以 Enterprise-Bench 评测模型在多版本数据、跨系统信息与角色权限下的表现，称 GPT-6.1 Sol 在推理、速度与成本间取得平衡。该案例为发布方自述，未提供独立验证。

  • DevRev 用 GPT-6.1 Sol 为 Computer 和 Operator 提供推理、规划与工具选择能力。
  • 其 Agent Studio 允许用户以对话描述工具行为，并用固定规则约束部分行为。
  • Enterprise-Bench 评测多版本数据、跨系统信息与角色权限下的模型表现。
