扩大对 Google Cloud TPU 及服务的使用

Anthropic 宣布扩大与 Google Cloud 的合作，计划使用最多一百万块 TPU，大幅增加算力资源。

具体内容

Anthropic 宣布扩大与 Google Cloud 的合作，计划使用最多一百万块 TPU，大幅增加算力资源。该扩展价值数十亿美元，预计 2026 年上线超过 1 吉瓦容量。Anthropic 称其企业客户超过 30 万家，大客户数量过去一年增长近 7 倍。公司采用 TPU、Trainium 和 GPU 多平台策略，并继续与亚马逊合作 Project Rainier。此外，Anthropic 向 METR 提供员工级访问权限以评估系统安全，并与 Hugging Face 等机构进行早期讨论。

  • Anthropic 计划使用最多一百万块 Google Cloud TPU，扩展价值数十亿美元。
  • 预计 2026 年上线超过 1 吉瓦容量，服务超 30 万企业客户。
  • 维持 TPU、Trainium 和 GPU 多平台算力策略。
