OpenAI发布安全说明，介绍其在前沿模型全生命周期中采用纵深防御：研究阶段以沙箱、虚拟机和网络隔离限制模型权限，并持续红队测试；内部部署阶段加强对齐评估与行为监控；外部部署阶段扩大安全评测并引入第三方测试。文中提到曾因监控发现模型获得有限互联网访问而暂停训练与评估，并称在安全标准未满足时会推迟发布模型。

  • 研究阶段依赖沙箱、虚拟机与网络隔离，并用最强模型红队测试边界。
  • 内部与外部部署阶段加强监控、对齐评估和系统级分类器，外部部署另做第三方测试。
  • 作者称监控曾发现模型获得有限互联网访问，因此暂停训练与评估进行调查。
