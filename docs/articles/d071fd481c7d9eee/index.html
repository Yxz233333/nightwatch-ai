Codex CLI 0.93.0 发布

Codex CLI 发布 0.93.0 版本。

具体内容

Codex CLI 发布 0.93.0 版本。更新日志显示，新增可选的 SOCKS5 代理监听并带策略执行与配置开关；计划模式可将拟定计划流式显示在专用 TUI 视图，并提供受特性开关控制的 /plan 快捷方式；新增 /apps 浏览连接器；应用服务器支持外部认证模式；智能审批默认启用，对 MCP 工具调用给出明确审批提示；引入基于 SQLite 的日志数据库。此外修复了 MCP 图像输出渲染、输入历史恢复图片附件、文件搜索性能等问题。

  • 新增可选 SOCKS5 代理监听，带策略执行与配置开关
  • 计划模式将拟定计划流式显示在专用 TUI 视图
  • 智能审批默认启用，MCP 工具调用有明确审批提示
  • 引入 SQLite 日志数据库，支持线程 ID 过滤与保留策略

CLI 稳定版本；桌面端功能另以对应公告为准。
