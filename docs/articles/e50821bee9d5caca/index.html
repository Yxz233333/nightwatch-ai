具体内容

Codex CLI 0.104.0 发布，新增网络代理中的 WebSocket 代理环境变量支持，应用服务器 v2 在线程归档或取消归档时发出通知，协议与核心层为命令审批携带独立审批 ID。修复方面，恢复或分叉流程中 Ctrl+C/Ctrl+D 可干净退出当前工作目录变更提示，并减少因依赖响应头模型而产生的误报安全降级。文档与发布流程也做了相应更新。

  • 新增 WS_PROXY/WSS_PROXY 环境变量支持 WebSocket 代理。
  • 应用服务器 v2 在线程归档或取消归档时发出通知，客户端无需轮询。
  • 命令审批引入独立审批 ID，支持单条 shell 命令中的多次审批。

CLI 稳定版本；桌面端功能另以对应公告为准。
