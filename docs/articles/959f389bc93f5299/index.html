OpenAI 更新 ChatGPT 的定时任务功能：侧边栏新增“Scheduled”页面，用户可集中查看活动任务、下次运行时间，并进行暂停、恢复、编辑或删除。任务整体更快更可靠，可按具体时间或上午、下午、晚上等时间窗口安排；监控类任务可搜索网页并检查已连接应用的变化，仅在值得报告时通知。该功能向 Plus、Pro、Business 和 Enterprise 用户推出，活动任务上限因套餐而异，任务每小时最多运行一次，无人值守任务可能在一段时间无活动后自动暂停。Pulse 将停用，Pro 用户自发布日起仍可访问 14 天。

  • 新增 Scheduled 页面，可集中查看、暂停、编辑或删除任务。
  • 支持按具体时间或上午、下午、晚上等窗口安排任务。
  • 向 Plus、Pro、Business、Enterprise 推出，任务每小时最多运行一次。
