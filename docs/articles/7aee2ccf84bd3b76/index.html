AnyLanguageModel 1.0：Apple 平台本地模型的一年

具体内容

本文回顾 AnyLanguageModel 发布一年后的 1.0 版本。该项目是 Apple Foundation Models 框架的替代实现，开发者只需把 import 语句从 FoundationModels 改为 AnyLanguageModel，同一套会话代码即可调用系统模型、经 llama.cpp、MLX、Core ML 运行的开放权重模型，以及 OpenAI、Anthropic、Gemini、Ollama 等托管服务。作者称工具调用与引导式生成已覆盖所有提供方，并新增图像输入、推理块记录和基于闭包的 API 密钥获取；配套的 swift-huggingface 与 swift-xet 1.0 用于加速模型下载。文中还列出若干可在 iPhone 或 Mac 上运行的开放权重模型，并预告后续将支持决策类与语音类模型。

  • 以替换 import 的方式兼容 Foundation Models API，同一会话代码可切换本地与托管模型。
  • 作者称工具调用、引导式生成已覆盖所有提供方，并新增图像输入与推理块记录。
  • 配套 swift-huggingface、swift-xet 1.0 提供从 Hub 加速下载模型的能力。

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
