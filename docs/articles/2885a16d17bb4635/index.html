OpenAI 更新 ChatGPT 工作使用活动研究

OpenAI 通过 Signals 数据观察不同国家与职业活动中的 ChatGPT 使用分布，提供季度变化的描述性分析。

具体内容

OpenAI 通过 Signals 数据观察不同国家与职业活动中的 ChatGPT 使用分布，提供季度变化的描述性分析。

  • 研究覆盖约100个国家的165类工作活动，时间范围为2025年第一季度至2026年第三季度。
  • 使用活动数据描述任务分布，不能直接证明就业变化或因果关系。
