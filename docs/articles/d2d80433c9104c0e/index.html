ChatGPT 模型选择器更新

OpenAI 简化了 ChatGPT 的模型选择器，让用户更容易选择所需的推理级别。

具体内容

OpenAI 简化了 ChatGPT 的模型选择器，让用户更容易选择所需的推理级别。Plus、Pro、Business、Enterprise 和 Edu 账户用户将根据其计划看到不同的模型选项，包括 Instant（快速响应日常问题）、Thinking（复杂任务深度推理）和 Pro（最先进的推理模型）。用户可通过 Configure 菜单启用 Auto 功能，自动在 Instant 和 Thinking 之间切换。此外，重试菜单也得到简化，便于使用 Thinking 或 Pro 模型重新生成回复。

  • 模型选择器简化为 Instant、Thinking、Pro 三档，按账户计划显示不同选项。
  • Auto 功能需在 Configure 中开启，可自动切换 Instant 与 Thinking。
  • 重试菜单简化，点击回复下方三点即可用 Thinking 或 Pro 重新生成。
