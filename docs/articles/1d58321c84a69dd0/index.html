具体内容

DeepSeek 官方发布信息显示，其 API 现已支持 V4-Pro 与 V4-Flash 两个新模型，可通过 OpenAI ChatCompletions 接口和 Anthropic 接口调用。接入时 base_url 保持不变，只需把 model 参数设为 deepseek-v4-pro 或 deepseek-v4-flash。原有 deepseek-chat 与 deepseek-reasoner 两个模型名将在三个月后（2026-07-24）停用；过渡期内它们分别指向 deepseek-v4-flash 的非思考模式与思考模式。当前收录材料未提供模型参数、能力评测或定价等细节。

  • API 新增 V4-Pro 与 V4-Flash，支持 OpenAI ChatCompletions 和 Anthropic 两种接口。
  • 接入时 base_url 不变，model 参数改为 deepseek-v4-pro 或 deepseek-v4-flash。
  • deepseek-chat 与 deepseek-reasoner 将于 2026-07-24 停用，过渡期分别指向 V4-Flash 的非思考与思考模式。
