测量大语言模型对 N-day 漏洞利用的影响

该稿件评估大语言模型加速和自动化 N-day 漏洞利用开发的能力。

具体内容

该稿件评估大语言模型加速和自动化 N-day 漏洞利用开发的能力。N-day 指已公开披露但仅部分设备修补的漏洞，攻击者可在补丁间隙利用未修补系统。作者在 18 个近期 Firefox 安全补丁上测试，称其最强模型 Claude Mythos Preview 自主构建了 8 个可工作的代码执行利用；在 21 个 Windows 内核补丁上生成 8 条完整利用链，将低权限用户提升至 SYSTEM 控制。作者还发现关闭防护的公开模型也能构建利用，但数量较少。摘要表示，这意味着补丁间隙中的威胁显著增大，防御方应加快补丁部署。
