Codex CLI 0.39.0 为稳定版本发布，新增 /review 命令。合并的 PR 涉及多项修复与调整：分离对话与沙箱的工作目录关注点、重构记录视图以处理 HistoryCells、修复 TUI 通知缺失报错、改用 tokio 互斥锁与异步函数避免阻塞工作线程、修复 Rust 引用细节、在 TUI 退出时提示 codex resume、使 ESC 在自动压缩时可用、统一动画、切换到 uuid_v7 并收紧 ConversationId 使用等。

  • 新增 /review 命令
  • 修复 TUI 通知缺失报错，并让 ESC 在自动压缩时可用
  • 改用 tokio 互斥锁与异步函数以避免阻塞工作线程

CLI 稳定版本；桌面端功能另以对应公告为准。
