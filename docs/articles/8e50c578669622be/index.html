具体内容

OpenAI 宣布 Decisions API 正式可用，该接口基于 GPT-6 Luna，面向应用和智能体工作流中大量“小决策”场景，例如输入分类、请求路由和下一步动作选择。官方称其针对有界答案问题，可从文本、图像和结构化输入中做出近实时判断，速度最高为经 Responses API 调用 GPT-6 Luna 的 10 倍。相比公测，新增 GPT-Live 原生集成、提示缓存、美欧推理驻留，并支持原生 JSON 输入、图像指令及单次最多 400 个问题。

  • 基于 GPT-6 Luna，官方称决策速度最高为经 Responses API 调用的 10 倍。
  • 支持概率、选项和评分三类答案，可处理文本、图像与原生 JSON 输入。
  • 新增 GPT-Live 原生集成、提示缓存及美欧推理驻留，单次最多 400 问。

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
