将 Agent Skills 捐赠给 Agentic AI Foundation

该文宣布将 Agent Skills 这一开放标准捐赠给 Linux 基金会下的 Agentic AI Foundation（AAIF）。

具体内容

该文宣布将 Agent Skills 这一开放标准捐赠给 Linux 基金会下的 Agentic AI Foundation（AAIF）。Agent Skills 以包含 SKILL.md 的文件夹形式，为 AI 代理提供特定任务或领域的流程知识；自 2025 年 12 月发布标准以来，已有 70 多个代理平台接入。此次捐赠包括名称、标识、GitHub 组织及 agentskills.io 域名，由多家公司工程师以个人身份维护，并计划推进版本化发布、正式提案流程与安全指引。

  • Agent Skills 以含 SKILL.md 的文件夹向代理传授特定任务或领域知识。
  • 自 2025 年 12 月发布标准以来，已有 70 多个代理平台接入。
  • 捐赠范围含名称、标识、GitHub 组织与 agentskills.io 域名。

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
