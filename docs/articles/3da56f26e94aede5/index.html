OpenAI 技术员工 Michael Bolin 撰文介绍 Codex 沙箱：Codex 常在用户本机执行命令，因此团队用各操作系统自带的沙箱机制约束命令的文件系统与网络访问，而非把计算搬进虚拟机或容器。文章说明默认权限配置（如 :workspace 允许写工作区、.git 与 .codex 只读、默认断网）、权限配置文件的继承与分层、企业通过 requirements.toml 限制可选配置，以及 codex sandbox 命令和 MCP 服务器加固示例。作者强调沙箱只是纵深防御的一层，仍需训练与对齐配合。

  • 默认 :workspace 允许写工作区，但 .git、.codex 等目录只读，并默认禁用网络访问。
  • 沙箱复用 macOS、Linux、Windows 各自机制，通过统一 API 启动受约束的子进程。
  • codex sandbox 命令可独立于代理会话，为任意命令或 MCP 服务器套用权限配置。
