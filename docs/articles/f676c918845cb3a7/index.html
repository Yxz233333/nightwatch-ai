英国主权人工智能新篇章：OpenAI 扩大与英国合作

OpenAI 宣布扩大与英国的合作，与英国司法部达成新协议，将 ChatGPT 引入公务员系统。

具体内容

OpenAI 宣布扩大与英国的合作，与英国司法部达成新协议，将 ChatGPT 引入公务员系统。同时，OpenAI 为 ChatGPT Enterprise、ChatGPT Edu 和 API 平台推出英国数据驻留功能，以支持可信、安全的人工智能应用。官方表示，这些举措旨在帮助英国公共部门在保障数据安全的前提下采用人工智能工具。

  • OpenAI 与英国司法部达成协议，将 ChatGPT 提供给英国公务员使用。
  • ChatGPT Enterprise、ChatGPT Edu 和 API 平台新增英国数据驻留功能。
  • 合作旨在支持英国公共部门在安全可信的前提下采用人工智能。
