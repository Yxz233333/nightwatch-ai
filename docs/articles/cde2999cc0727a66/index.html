具体内容

官方发布说明称，Voice 现已在网页、iOS 和 Android 上支持插件。用户可在语音对话中调用账户已有的插件和已连接应用，并在聊天中查看文字回复。Voice 也进入 Work 的网页端和移动端，可要求其创建文档、演示文稿和表格、使用已连接应用或在浏览器中操作；在 Work 中结束语音通话后，未完成任务可转为文字继续。Free 和 Go 用户可在 Chat 中使用其套餐支持的插件，Work 中的 Voice 需同时具备 Voice 与 Work 权限，原有应用连接、权限和用量限制继续适用。

  • Voice 在网页、iOS、Android 支持插件，可在对话中调用账户已有插件与连接应用。
  • Work 中的 Voice 可创建文档、演示文稿和表格，通话结束后未完成任务可转文字继续。
  • Free 和 Go 用户可用套餐支持的插件；Work 中的 Voice 需同时具备 Voice 与 Work 权限。
