Claude 玩转机器人

具体内容

该稿件测试语言模型能力能否迁移到机器人领域：模型能否感知场景、理解特定机器人状态，并发出能在物理世界可靠产生变化的动作。作者让多个语言模型控制多种机器人本体，包括经典控制玩具、仿真四足与人形、机械臂及真实 Unitree Go2，并提供从直接输出力矩到编写控制器代码、强化学习训练、向预训练策略下达高层指令等多种控制接口。结果显示，能力高度依赖连接方式：直接驱动关节大多失败，而监督预训练控制器或使用简单方向工具时可完成真实导航与操作任务。

  • 测试覆盖经典控制、运动导航与机械臂操作三类任务
  • 直接驱动关节多失败，监督预训练策略时表现较好
  • 新模型在调整策略与图像到动作转换上进步明显
