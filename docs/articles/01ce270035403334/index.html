GPT-5.3-Codex 与 GPT-5.2 已弃用

官方发布说明称，对使用 ChatGPT 账号登录的用户，GPT-5.3-Codex 和 GPT-5.2 已不再作为 Codex 中可选模型；使用 API 密钥的工作流不受影响。

具体内容

官方发布说明称，对使用 ChatGPT 账号登录的用户，GPT-5.3-Codex 和 GPT-5.2 已不再作为 Codex 中可选模型；使用 API 密钥的工作流不受影响。官方建议改用当前 Codex 模型，如 GPT-5.5、GPT-5.4 或 GPT-5.4 mini，并指向 Codex 模型可用性与定价页面查询额度费率。该更新属于模型可选范围调整，具体可用性以原文页面为准。

  • API 密钥工作流不受此次弃用影响。
  • 官方建议改用 GPT-5.5、GPT-5.4 或 GPT-5.4 mini。
