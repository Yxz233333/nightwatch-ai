ChatGPT中的餐厅预订功能

ChatGPT现在可通过OpenTable、Resy和Yelp帮助用户查找可用的餐厅预订。

具体内容

ChatGPT现在可通过OpenTable、Resy和Yelp帮助用户查找可用的餐厅预订。用户可在对话中说明地点、时间、用餐人数及菜系、预算、饮食需求或氛围等偏好，回复中会直接显示可预订时段，并可追问缩小范围或查询特定餐厅，选定时间后可直接预订。该功能正面向所有ChatGPT套餐在移动端、网页端和桌面端推出；OpenTable覆盖全球，Resy限美国，Yelp限美国与加拿大。ChatGPT Work不包含餐厅预订搜索。

  • ChatGPT可经OpenTable、Resy和Yelp查找并直接预订餐厅。
  • 用户可提供地点、时间、人数与饮食偏好等信息。
  • 面向所有套餐在移动端、网页端和桌面端推出，ChatGPT Work不含此功能。
