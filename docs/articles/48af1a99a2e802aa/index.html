官方发布 Claude Fable 5，称其为 Mythos 级模型并已做通用安全处理，能力超过此前所有公开发布的模型，在软件工程、知识工作、视觉、科研等测试基准上表现领先。为控制网络安全等风险，部分话题查询会转由 Claude Opus 4.8 回答，作者称该保护平均在不足 5% 的会话中触发。同时向少数网络安全防御者和基础设施提供商推出 Claude Mythos 5，底层模型相同但部分领域解除保护，初期通过 Project Glasswing 与美国政府合作部署。两者定价为每百万输入 token 10 美元、输出 50 美元。

  • 定价为每百万输入 10 美元、输出 50 美元
