NVIDIA 重塑欧洲零售：从数字发现到实体运营

该文为 NVIDIA 官方发布，介绍欧洲零售商借助开放模型与物理智能推进零售场景。

具体内容

该文为 NVIDIA 官方发布，介绍欧洲零售商借助开放模型与物理智能推进零售场景。文中列举 Shopify 后训练 Nemotron 3.5 Lightning 用于 Sidekick 子代理、Zooplus 商品发现原型、Photoroom 图像标准化、Omi 与欧莱雅的数字孪生及分子模拟，以及 Otto Group 仓储仿真、ALLSIDES 数字孪生工厂等。作者声称这些案例在成本、速度或转化上取得改善，并展示面向零售的蓝图。相关测试与预览不等同于全面上线。

  • Shopify 称后训练模型在内部基准上准确率超过前沿模型，服务成本降九成、响应快七倍。
  • Zooplus 在 AWS 环境部署原型，称语义检索达到 86% 搜索准确率。
  • Otto Group 在仿真中设计并测试仓库运营，再推进实体实施。
