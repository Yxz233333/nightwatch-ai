具体内容

Anthropic 发布文章称，其内部研究模型 Claude 在不到半小时内查明了 NIST P-192、P-224、P-256、P-384、P-521 等椭圆曲线标准种子的生成方式。作者表示，这些种子并非来自哈希算法，而是 1990 年代 C 库 lrand48 随机数生成器的输出，并以 Unix 时间戳初始化。文章强调这不是密码学破解或新攻击，反而降低了曲线被植入后门的可能性。该结论来自 Anthropic 单方发布，尚待独立验证。

  • Claude 推断 NIST 曲线种子来自 lrand48 随机数生成器，而非哈希算法。
  • 作者称种子由 Unix 时间戳初始化，相关时间集中在 1997 至 1998 年。
  • 文章强调这不是新攻击或弱点，并称降低了后门担忧。
