ChatGPT 中的 Outlook 共享邮箱与日历

具体内容

ChatGPT 的 Outlook 邮件与日历应用现可在用户拥有权限时处理委派或共享的 Outlook 资源。用户可让 ChatGPT 读取共享邮箱邮件、浏览文件夹、标记已读或未读、移动邮件，并以该邮箱名义发送纯文本邮件；对共享日历可创建、更新、回复、取消、删除事件或添加小附件。使用时需连接应用并提供准确的共享邮箱地址或目标日历，可用性取决于微软权限与工作区应用设置。

  • 可读取共享邮箱邮件、浏览文件夹、标记已读未读、移动邮件并发送纯文本邮件。
  • 可对共享 Outlook 日历创建、更新、回复、取消、删除事件或添加小附件。
  • 需连接 Outlook 应用并提供准确共享邮箱地址或目标日历，可用性受微软权限限制。
