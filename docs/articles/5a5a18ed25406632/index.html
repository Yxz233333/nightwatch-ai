测量 Claude 中的政治偏见

Anthropic 发布并开源了一套自动评估政治中立性的方法，用“配对提示”测试模型对同一政治议题的正反立场是否回应一致。

具体内容

Anthropic 发布并开源了一套自动评估政治中立性的方法，用“配对提示”测试模型对同一政治议题的正反立场是否回应一致。评估覆盖9类任务、150个话题、1350对提示，测试了 Claude Sonnet 4.5、Claude Opus 4.1 及 GPT-5、Gemini 2.5 Pro、Grok 4、Llama 4 Maverick。作者报告 Claude Opus 4.1 和 Sonnet 4.5 的中立性得分分别为95%和94%，并强调比较受模型配置差异影响。

  • 采用配对提示法，从正反政治视角测试模型回应是否均衡。
  • 评估覆盖1350对提示、9类任务和150个话题，并开源评分方法。
  • 作者报告 Claude Opus 4.1 与 Sonnet 4.5 中立性得分分别为95%和94%。
