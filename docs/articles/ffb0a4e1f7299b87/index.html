OpenAI推出两种新方式将Slack与ChatGPT结合：一个将Slack上下文引入ChatGPT的连接器，以及一个可在Slack内与ChatGPT对话的ChatGPT应用。用户可在Slack侧边栏中提问、总结长线程、起草回复并搜索消息和文件，聊天记录也会同步至ChatGPT侧边栏。

  • 推出Slack连接器与ChatGPT应用两种集成方式
  • 支持在Slack内总结线程、起草回复和搜索
  • 聊天记录跨平台同步，语义搜索限特定套餐
