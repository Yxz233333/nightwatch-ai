Codex CLI 0.97.0 稳定版发布，更新日志列出新功能、修复与杂项。新增会话级“允许并记住”工具审批、技能文件变更实时检测、动态工具输出支持图文混合、TUI 的 /debug-config 命令、线程记忆摘要的初期记忆管道，以及可配置 log_dir。修复涉及 TUI 选择器抖动、工作状态指示、云需求可靠性与待处理输入事件持久化，并新增 Linux Bubblewrap 沙箱路径等。

  • 新增会话级“允许并记住”审批，同一工具在会话内可自动批准
  • 新增技能文件实时更新检测与 /debug-config 配置查看命令
  • 引入线程记忆摘要初期管道，并新增可配置 log_dir

CLI 稳定版本；桌面端功能另以对应公告为准。
