Anthropic 介绍推理提取与蒸馏攻击防护措施

Anthropic 介绍增强蒸馏防护的方法，包括限制受保护推理内容的跨账户流转、分类器检测提取尝试，以及对重复滥用账户施加限制。

具体内容

Anthropic 介绍增强蒸馏防护的方法，包括限制受保护推理内容的跨账户流转、分类器检测提取尝试，以及对重复滥用账户施加限制。公司报告其平台上被提取的推理 token 数下降约90%至99%，同时承认集成调整、误判和被拦截请求计费等代价。这是厂商对自身防护的报告，不能当作独立安全审计结论。

  • 防护针对未经授权的大规模推理提取，与一般合法使用及研究需区分。
  • 官方称分类器误判率低于0.1%，仍承认存在正常请求受影响的情况。
  • 文章发布于10月12日，本次补入历史，不混入今日推荐。
