Codex CLI 0.118.0 稳定版发布，新增 Windows 沙箱代理网络支持、ChatGPT 设备码登录、codex exec 支持提示加标准输入工作流，以及自定义模型提供商动态刷新短期令牌。同时修复了项目本地 .codex 文件保护、Linux 沙箱 bwrap 查找、TUI 工作流恢复和 MCP 启动健壮性等问题。

  • Windows 沙箱支持仅代理网络，使用操作系统级出口规则。
  • 新增 ChatGPT 设备码登录和 codex exec 标准输入管道支持。
  • 修复项目本地 .codex 文件首次创建时的保护缺口。

CLI 稳定版本；桌面端功能另以对应公告为准。
