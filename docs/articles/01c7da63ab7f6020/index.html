DeepSeek-V4-Pro 正式版更新

DeepSeek 官方宣布 DeepSeek-V4-Pro 正式版（GA）已在 APP、Web 和 API 上线，API 调用方式不变，模型名设为 deepseek-v4-pro 即可。

具体内容

DeepSeek 官方宣布 DeepSeek-V4-Pro 正式版（GA）已在 APP、Web 和 API 上线，API 调用方式不变，模型名设为 deepseek-v4-pro 即可。官方称该版本大幅增强智能体能力，生产环境提升尤为明显，并列出 HLE、Terminal Bench 2.1、NL2Repo 等多项基准分数。API 现原生支持 OpenAI Responses API 格式并适配 Codex；V4-Pro 与 V4-Flash 的思考模式支持 low/high/max 三档。官方还宣布改为峰谷定价，谷时价格为峰时一半，新价格自 2026 年 8 月 16 日 16:00（UTC）生效。

  • 正式版已在 APP、Web、API 上线，模型名仍为 deepseek-v4-pro。
  • 官方称智能体能力显著增强，并公布多项基准测试分数。
  • API 原生支持 OpenAI Responses API 格式并适配 Codex。
  • 思考模式新增 low/high/max 三档，并改为峰谷定价。
