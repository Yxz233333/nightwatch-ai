GPT-5.5 Instant Mini 在 ChatGPT 中上线

官方发布信息显示，ChatGPT 正在推出 GPT-5.5 Instant Mini，用它替代 GPT-5.3 Instant Mini，作为用户触及 GPT-5.5 Instant 或 Auto 速率限制后使用的回退模型。

具体内容

官方发布信息显示，ChatGPT 正在推出 GPT-5.5 Instant Mini，用它替代 GPT-5.3 Instant Mini，作为用户触及 GPT-5.5 Instant 或 Auto 速率限制后使用的回退模型。由于定位为回退模型，它不会出现在模型选择器中，此次更新也不影响 API 或 Codex。官方称，与 GPT-5.3 Instant Mini 相比，新模型更能跟踪用户意图变化、校准语气，并减少重复或过度结构化的回答；测试还显示个性化更强、事实性问题更少。

  • GPT-5.5 Instant Mini 取代 GPT-5.3 Instant Mini 成为 ChatGPT 回退模型。
  • 该模型不进入模型选择器，且此次更新不影响 API 与 Codex。
  • 官方称其在意图跟踪、语气校准和减少事实性问题上有改进。
