Codex CLI 0.53.0 发布

据官方发布记录，Codex CLI 0.53.0 为稳定版本更新，重点包括修复 error 400 问题、改进 Java 沙箱支持。

具体内容

据官方发布记录，Codex CLI 0.53.0 为稳定版本更新，重点包括修复 error 400 问题、改进 Java 沙箱支持。合并的 PR 涉及新增开发者指令、移除部分序列化注解、更新 macOS 上 Java 的 Seatbelt 策略、引入 Windows 沙箱 alpha 版本、将 Windows 栈大小提升至 8 MB、移除末轮推理过滤、拆分 app-server API 类型为 v1 与 v2、新增 /exit 斜杠命令别名、限流错误返回绝对时间，以及为 gpt-5-codex 覆盖 verbosity 等。桌面端功能以对应公告为准。

  • 重点修复 error 400 问题并改进 Java 沙箱支持
  • 引入 Windows 沙箱 alpha 版本，Windows 栈大小提至 8 MB
  • 新增 /exit 命令别名，限流错误改为返回绝对时间

CLI 稳定版本；桌面端功能另以对应公告为准。
