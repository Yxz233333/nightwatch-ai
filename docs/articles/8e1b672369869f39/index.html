Codex 仓库组件：Python SDK 0.154.0 发布

该版本可通过 pip 升级安装，要求 Python 3.10 及以上，并附带匹配的 CLI 运行时。

具体内容

该版本可通过 pip 升级安装，要求 Python 3.10 及以上，并附带匹配的 CLI 运行时。更新新增 max 与 ultra 两档推理强度，在同步和异步 run()、turn() 中引入 ExternalMessage，并增加恢复/分叉时的 include_turns、单轮 turn_service_tier 及 source 元数据。发布说明还列出 HookMetadata 结构、通知类型和轮次句柄事件收集方式等升级迁移注意事项。

  • 新增 max 与 ultra 推理强度取值，并加入 ExternalMessage 支持外部内容发起或加入轮次。
  • 恢复/分叉新增 include_turns，单轮可设 turn_service_tier，并补充 source 元数据。
  • 升级需注意 HookMetadata 改用 .root 访问，部分通知改为类型化载荷。

CLI 稳定版本；桌面端功能另以对应公告为准。
