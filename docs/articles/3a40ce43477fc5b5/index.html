官方发布说明称，ChatGPT 定时任务现可在 Gmail、Slack 或 GitHub 出现受支持事件时运行：可按发件人或主题筛选 Gmail 邮件、监视指定 Slack 频道，或响应拉取请求的评审、评论、提交更新与合并等活动。该功能在网页端和移动端面向符合条件的套餐提供；创建任务前需连接相应应用并批准其请求的访问权限，Slack 应用须为所监视频道成员，GitHub 应用须能访问所监视仓库。事件触发任务不能同时使用基于时间的计划；相近事件可能被合并为一次运行。

  • 支持按发件人或主题筛选 Gmail，并监视指定 Slack 频道
  • 可响应拉取请求的评审、评论、提交更新和合并事件
  • 事件触发任务不能同时设置基于时间的计划
