macOS 版 ChatGPT 的 Computer History 功能

官方说明介绍，Computer History 是 ChatGPT macOS 应用中的可选功能，让 ChatGPT 和 Codex 参考用户在应用与网站中的部分活动，减少重复说明。

具体内容

官方说明介绍，Computer History 是 ChatGPT macOS 应用中的可选功能，让 ChatGPT 和 Codex 参考用户在应用与网站中的部分活动，减少重复说明。它记录交互事件，而非截图、录屏、麦克风输入或系统音频，且不含隐私浏览。该功能默认关闭，面向 Pro、Business 和 Enterprise 用户；企业管理员须先授权。用户可暂停、选择纳入的应用与网站，并查看或删除时间线条目。目前不适用于欧洲经济区、英国和瑞士。

  • 记录应用与网站交互事件，不含截图、录屏和音频
  • 默认关闭，Pro、Business、Enterprise 可用且企业需管理员授权
  • 用户可暂停、选择范围并查看或删除时间线条目
