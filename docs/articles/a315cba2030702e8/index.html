Codex CLI 0.46.0 发布

Codex CLI 0.46.0 发布，重点改进 MCP 支持，包括支持可流式 HTTP 服务器及可选的 bearer token 或 OAuth 登录。

具体内容

Codex CLI 0.46.0 发布，重点改进 MCP 支持，包括支持可流式 HTTP 服务器及可选的 bearer token 或 OAuth 登录。用户需在 config.toml 中启用 experimental_use_rmcp_client = true 以使用新 MCP 栈。更新还包含多项修复与 TUI 改进，如修复 bearer token 授权头、新增 list_dir 和 grep_files 工具、调整终端渲染等。官方希望尽快移除实验标志并持续扩展 MCP 支持。

  • 改进 MCP 支持，新增可流式 HTTP 服务器及可选 bearer token 或 OAuth 登录。
  • 需启用 experimental_use_rmcp_client = true 使用新 MCP 栈。
  • 新增 list_dir 和 grep_files 工具，并包含多项 TUI 修复。

CLI 稳定版本；桌面端功能另以对应公告为准。
