Anthropic与Infosys合作，为电信等受监管行业构建AI智能体

Anthropic与Infosys宣布合作，面向电信、金融服务、制造和软件开发等领域开发并交付企业级AI解决方案。

具体内容

Anthropic与Infosys宣布合作，面向电信、金融服务、制造和软件开发等领域开发并交付企业级AI解决方案。合作将Anthropic的Claude模型与Claude Code同Infosys Topaz平台结合，帮助企业在满足受监管行业所需的治理与透明度要求下加快软件开发。双方称重点方向是智能体AI，即能独立处理理赔、生成与测试代码、管理合规审查等多步骤任务的系统，并计划借助Claude Agent SDK帮助客户构建可长时间持续工作的智能体，同时推动遗留系统现代化。原文还提到印度是Claude.ai第二大市场。

  • 合作将Claude与Claude Code接入Infosys Topaz平台。
  • 重点为电信、金融、制造等受监管行业构建智能体AI。
  • 双方计划用Claude Agent SDK支持长流程任务与遗留系统迁移。
