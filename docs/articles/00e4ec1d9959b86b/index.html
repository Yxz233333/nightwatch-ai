Codex CLI 0.113.0 为稳定版本更新，新增内置 request_permissions 工具，使运行中的回合可在运行时申请额外权限，并在 TUI 中渲染审批调用；插件工作流扩展了市场发现、元数据、安装时鉴权与卸载端点；app-server 命令执行支持流式输入输出与 TTY/PTY；网页搜索支持完整工具配置；还引入权限配置语言与更细的沙箱策略。此外修复了鉴权、Windows 执行、插件加载与网络代理解析等问题。

  • 新增 request_permissions 工具支持运行时申请权限
  • app-server 命令执行支持流式 IO 与 TTY/PTY
  • 新增权限配置语言并拆分文件系统与网络沙箱策略

CLI 稳定版本；桌面端功能另以对应公告为准。
