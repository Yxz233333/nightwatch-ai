为网络防御者构建 AI

该官方发布称，AI 模型在网络安全任务中已具备实用价值。

具体内容

该官方发布称，AI 模型在网络安全任务中已具备实用价值。团队投入研究提升 Claude 在代码与已部署系统中发现、分析并修复漏洞的能力，成果体现在 Claude Sonnet 4.5 上，其在发现代码漏洞等网络安全技能上可匹敌或超过两个月前发布的 Opus 4.1。文中还提到 DARPA AI Cyber Challenge 中团队用大模型查找并修补漏洞，以及 Safeguards 团队发现并阻断利用 Claude 的勒索与间谍活动，认为网络安全正处拐点。

  • Sonnet 4.5 在发现代码漏洞等网络安全技能上可匹敌或超过 Opus 4.1
  • 研究聚焦防御性任务：发现漏洞、修补漏洞、测试模拟基础设施
  • Safeguards 团队称发现并阻断利用 Claude 的勒索与间谍活动
