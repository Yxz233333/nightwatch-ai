NVIDIA DGX Spark 开发者套件把桌面变成超级计算实验室

NVIDIA 在 SC26 超算大会上推出面向研究人员、学术人员和开发者的 DGX Spark HPC 开发者套件。

具体内容

NVIDIA 在 SC26 超算大会上推出面向研究人员、学术人员和开发者的 DGX Spark HPC 开发者套件。该方案可从单节点扩展到四台DGX Spark环形直连集群，无需额外交换机，四节点时合计提供512GB内存和20TB NVMe存储，让团队在桌面运行多节点科学计算与 AI 模型，而不必排队等待共享 GPU 集群。原文还列举了材料模拟、分子动力学、量子化学电路模拟等使用案例，并称 HPC SDK 使用实践指南即将发布。

  • 四节点 DGX Spark 通过 ConnectX-7 环形直连，合计 512GB 内存与 20TB 存储。
  • 原文称借助 NVFP4 可在四节点本地部署最多 700B 参数模型，如 DeepSeek V4.1。
  • 套件已在 SC26 展示并开售，NVIDIA HPC SDK 使用实践指南即将发布。
