We resolve the three-dimensional Ball–Evans approximation problem for every finite p > 2. Every $`W^{1,p}`$ homeomorphism between arbitrary bounded domains in ℝ3 can be approximated strongly in $`W^{1,p}`$ by smooth diffeomorphisms onto the same target.
