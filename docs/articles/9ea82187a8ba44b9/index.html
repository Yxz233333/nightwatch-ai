欧洲领先金融服务机构采用开放模型构建专有智能

该新闻汇总了在GTC Berlin上多家欧洲银行、支付公司与金融数据商的展示：它们基于NVIDIA加速计算、开放权重模型和自有基础设施构建生产级智能。

具体内容

该新闻汇总了在GTC Berlin上多家欧洲银行、支付公司与金融数据商的展示：它们基于NVIDIA加速计算、开放权重模型和自有基础设施构建生产级智能。Revolut以单一基础模型PRAGMA重建技术栈，初期服务8000万客户；Starling Bank在英国主权云上训练代理模型；Lloyds构建交易基础模型ATUM；bunq、NatWest、Modulr、Santander等也采用开放模型。新闻还提到LSEG、RavenPack、HSBC、Stripe在金融研究与欺诈检测上的加速效果。

  • Revolut基于NVIDIA加速计算以PRAGMA重建技术栈，初期服务8000万客户并设计可扩展3倍。
  • Starling Bank称其为首家在英国主权云上训练代理模型的银行，使用自有交易数据。
  • bunq称其代理助手Finn采用开放权重模型，每次回答成本为领先闭源模型的60%。
