Anthropic 扩大与 Google 和 Broadcom 的合作，获取数吉瓦下一代算力

Anthropic 宣布与 Google 和 Broadcom 签署新协议，获取数吉瓦的下一代 TPU 算力，预计从 2027 年开始上线。

具体内容

Anthropic 宣布与 Google 和 Broadcom 签署新协议，获取数吉瓦的下一代 TPU 算力，预计从 2027 年开始上线。Anthropic 首席财务官 Krishna Rao 称这是公司迄今最大规模的算力承诺，用于支持前沿 Claude 模型并满足客户需求。原文还提到，Claude 客户需求在 2026 年加速增长，年化收入超过 300 亿美元；大部分新增算力将设在美国。Anthropic 表示将继续使用 AWS Trainium、Google TPU 和 NVIDIA GPU 等多种硬件。

  • 协议涉及数吉瓦下一代 TPU 算力，预计 2027 年上线
  • Anthropic 称这是其迄今最大算力承诺
  • 大部分新增算力将部署在美国
