具体内容

Codex CLI 0.159.0 的版本说明列出多项新功能与修复。新功能包括可选的 instant_interrupt，让新输入在模型响应或长时间代码模式调用中引导 Codex；新会话采用紧凑欢迎屏和统一标题；警告查看器关闭时清除已读警告；计划确认时可滚动记录；原生 Mermaid 渲染支持更多流程图元素；应用服务器客户端可从指定条目分页线程历史。修复涉及 Windows 控制台窗口、复制 Markdown 表格、登录与沙箱网络等。

  • 新增可选 instant_interrupt，允许新输入在响应中引导 Codex
  • 改进 TUI 欢迎屏、警告查看器与 Mermaid 渲染
  • 修复 Windows 控制台窗口、复制格式与 macOS TLS 等问题

CLI 稳定版本；桌面端功能另以对应公告为准。
