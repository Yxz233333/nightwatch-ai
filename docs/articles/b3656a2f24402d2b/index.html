Codex CLI 0.114.0 发布，新增实验性代码模式与带 SessionStart、Stop 事件的实验性钩子引擎，并为 WebSocket 应用服务器增加健康检查端点。还加入禁用内置系统技能的配置开关，改进交接时的实时转录上下文和 $ 提及选择器。修复涉及 Linux tmux 崩溃、应用启用条件、恢复线程状态、权限兼容与审批持久化等问题。

  • 新增实验性代码模式和带 SessionStart、Stop 事件的实验性钩子引擎。
  • WebSocket 应用服务器新增 /readyz 与 /healthz 健康检查端点。
  • 修复 Linux tmux 崩溃、恢复线程卡住及权限与审批流程等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
