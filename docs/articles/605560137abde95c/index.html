ChatGPT for Healthcare 推出更多推进医疗护理的方式

OpenAI 发布 ChatGPT for Healthcare 更新，面向临床、研究与行政团队。

具体内容

OpenAI 发布 ChatGPT for Healthcare 更新，面向临床、研究与行政团队。稿件称新增可在现有医疗软件间执行多步操作的 computer-use agents，改进可信临床搜索对医学证据的查找、评估与引用，并引入 20 多个医疗插件，覆盖病历查阅、处方准备、保险资格核查等场景。作者还称盲评中医生在八项维度上对更新后回答评价更高。内容共享不用于训练模型，HIPAA 合规需使用 BAA 覆盖的服务。

  • 新增 computer-use agents，可读取屏幕、点击、输入并在医疗软件间切换完成多步工作。
  • 改进可信临床搜索，强调查找、评估并引用医学证据，供临床医生核查来源。
  • 新增 20 多个医疗插件，覆盖临床护理、护理协调与业务运营等场景。
  • Healthcare的插件受工作区管理员设置影响；Clinicians仅限符合资格、已验证的美国临床人员，只有部分插件可用。涉及受保护健康信息需合资格服务、BAA及对应安全设置。

官方已发布；需符合Healthcare工作区或美国Clinicians资格、管理员和服务配置要求。
