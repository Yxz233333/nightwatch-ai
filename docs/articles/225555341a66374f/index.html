Anthropic 与 NEC 合作打造日本最大 AI 工程团队

NEC 将向全球约 3 万名集团员工提供 Claude，并成为 Anthropic 首家日本本土全球合作伙伴。

具体内容

NEC 将向全球约 3 万名集团员工提供 Claude，并成为 Anthropic 首家日本本土全球合作伙伴。双方将面向日本市场共同开发安全、行业专用的 AI 产品，首批覆盖金融、制造和地方政府，并计划扩展到网络安全等领域。NEC 还将把 Claude 及 Claude Code 融入 BluStellar 业务方案，并设立卓越中心培养 AI 工程团队。

  • NEC 向约 3 万名集团员工部署 Claude，成为 Anthropic 首家日本全球合作伙伴。
  • 双方共同开发面向金融、制造、地方政府等领域的行业专用 AI 产品。
  • NEC 将 Claude 集成进安全运营中心服务，并设立卓越中心培养 AI 工程团队。
