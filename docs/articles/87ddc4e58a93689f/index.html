用 Claude 发现密码学弱点

Anthropic 称其研究人员使用 Claude Mythos Preview 发现改进的密码算法攻击方法。

具体内容

Anthropic 称其研究人员使用 Claude Mythos Preview 发现改进的密码算法攻击方法。其一针对后量子数字签名候选方案 HAWK，作者声称找到格中的非平凡自同构，使有效密钥强度减半；其二针对轮数缩减版 AES，作者声称减少一个攻击者需猜测的环节，使此前最佳攻击提速 200 至 800 倍。原文强调两项结果目前不影响任何生产系统：HAWK 仅为候选方案未部署，第二项也未攻破完整 AES。作者称过程大多自主完成，每项约耗 10 万美元 API 成本，并已按负责任披露流程与 HAWK 作者及 NIST 邮件列表协调公开。

  • 作者称对 HAWK 的攻击利用格自同构，使有效密钥强度减半。
  • 对轮数缩减版 AES 的攻击使此前最佳攻击提速 200 至 800 倍。
  • 原文强调不影响生产系统，HAWK 未部署、完整 AES 未被攻破。
