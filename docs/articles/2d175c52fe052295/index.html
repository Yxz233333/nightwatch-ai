推出 CARE-X：借助辅助监督、奖励对齐学习与工具增强测量，迈向临床可用的放射学视觉语言模型

微软研究院介绍研究模型 CARE-X，一个面向胸部 X 光多种解读任务的统一视觉语言模型。

具体内容

微软研究院介绍研究模型 CARE-X，一个面向胸部 X 光多种解读任务的统一视觉语言模型。稿件称其结合生成式报告与结构化预测，用分类、定位辅助头提供带置信度的输出，并以 DAPO 强化学习按临床正确性优化；另有一项独立实验将 Qwen3-VL-4B-Instruct 与确定性测量工具配对，考察直接计算能否改善心胸比等测量依赖判断。作者称模型在 Narayana Health 的真实印度临床数据上验证，但明确其为研究模型，非产品、非医疗器械，未经监管批准，结果属回顾性研究，不构成临床安全性或有效性证明。

  • CARE-X 以 SigLIP2 视觉编码器、Phi-4-mini 主干和任务辅助头组成，单次前向可同时输出文本与带置信度的结构化预测。
  • 作者称辅助定位头提升解剖与短语定位指标，DAPO 训练后生成式定位接近专用检测头。
  • 分类头提供可调阈值，作者称可在高敏感度筛查与高特异度确认间切换。
