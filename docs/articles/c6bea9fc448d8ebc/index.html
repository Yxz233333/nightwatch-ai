前沿科学：科学家如何使用ChatGPT

OpenAI经济研究团队基于“ChatGPT学术研究者夏季试点”，分析了1,819名科学家的逾58万条科研相关消息，并调查其中251人。

具体内容

OpenAI经济研究团队基于“ChatGPT学术研究者夏季试点”，分析了1,819名科学家的逾58万条科研相关消息，并调查其中251人。作者称，科学家将ChatGPT用于文献回顾、证据分析、代码编写和构思等环节；受访者估计同等质量工作若无AI耗时约为使用AI时的1.9倍，回答发现时间线问题的250人中，98%预期AI会加速本领域发现。研究还统计了构思消息中由科学家主导、共同完善和由ChatGPT提议的比例，以及科学家对回复进行追问核查的频率。OpenAI表示默认不用该项目数据训练模型，并以自动分类器归类消息、不读取原文。

  • 分析1,819名科学家的逾58万条消息，并调查251名参与者
  • 受访者估计同等质量工作若无AI耗时约为使用AI时的1.9倍
  • 回答发现时间线问题的250人中，98%预期AI将加速本领域科学发现
  • 时间与发现预期是参与者自报及相关性观察，不是AI导致效率提升或发现加速的因果证明。
