Codex 桌面应用发布 26.930 版本。新增功能支持将选中的多个对话一次性移动到某个项目中。性能与问题修复方面，改进了将托管工作树附加到对话时的恢复能力，修复了部分缩放级别下大型差异显示为空白的问题，并改善了排队消息发送失败或对话打开失败后的重试机制。官方未说明该版本的具体推出范围。

  • 支持将选中的多个对话一次性移入项目
  • 修复部分缩放级别下大型差异显示空白的问题
  • 改进工作树附加恢复及消息发送、对话打开失败后的重试
