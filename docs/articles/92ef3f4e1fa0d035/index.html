推出Daybreak Blue与Daybreak Red

Daybreak面向获批防御方推出两个访问层级：Daybreak Blue与Daybreak Red，用于在明确授权的任务中从安全发现推进到经验证的修复。

具体内容

Daybreak面向获批防御方推出两个访问层级：Daybreak Blue与Daybreak Red，用于在明确授权的任务中从安全发现推进到经验证的修复。摘要表示，Blue面向多数防御性安全工作，提供GPT-5.6 Sol等通用模型，用于漏洞发现、安全代码审查、检测工程、事件响应、恶意软件分析与补丁验证；Red则需单独审批，提供GPT-5.6 Cyber等专用模型，用于授权范围内的漏洞复现、利用验证、渗透测试与红队工作。访问须经Trusted Access for Cyber审批，且仅限获批身份、工作区或API组织及项目、模型和产品界面。

  • Daybreak Blue提供GPT-5.6 Sol等通用模型，覆盖漏洞发现与补丁验证等防御工作。
  • Daybreak Red需单独审批，提供GPT-5.6 Cyber用于授权渗透测试与红队。
  • 访问经Trusted Access for Cyber审批，仅限获批身份、工作区与产品界面。
