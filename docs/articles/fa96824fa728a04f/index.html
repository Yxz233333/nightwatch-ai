Windows 26.908版Pets与Appshots快捷聊天

该更新说明介绍ChatGPT桌面应用在macOS与Windows上的新功能。

具体内容

该更新说明介绍ChatGPT桌面应用在macOS与Windows上的新功能。用户可在其他应用中通过浮动的Pets控件输入快捷聊天并按回车发送，用@添加上下文、用$选择技能，还可通过铃铛图标跟踪线程进度。Windows版新增Appshots，按两个Alt键即可把最前台应用窗口的截图与可用文本分享给ChatGPT。此外还包含从来源面板打开文件、Codex应用快捷键等改进与修复。

  • Pets浮动控件支持快捷聊天，可用@添加上下文、$选择技能。
  • Windows版Appshots可按两个Alt键分享前台应用窗口截图与文本。
  • 新增从来源面板打开文件及Codex应用相关快捷键改进。
