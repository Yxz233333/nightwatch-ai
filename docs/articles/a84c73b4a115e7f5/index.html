Codex CLI 0.167.0 正式版发布

正式版扩展终端代理管理、后端切换和本地图片预览，并修复对话恢复与网络审批问题。

具体内容

正式版扩展终端代理管理、后端切换和本地图片预览，并修复对话恢复与网络审批问题。

  • codex agents --no-daemon 可打开代理管理中心，管理中心与会话选择器显示未读结果。
  • 终端可切换已连接后端并保留草稿，支持的终端可预览本地图片附件。
  • 系统代理设置须在 experimental 主动启用，Vertex AI 设置向导也需要启用。

已发布正式版；部分功能需要主动启用。
