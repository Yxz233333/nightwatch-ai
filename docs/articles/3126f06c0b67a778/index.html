Heimstaden 借助 AI 改变住宅房地产管理方式

OpenAI 官方发布案例称，欧洲住宅房地产运营商 Heimstaden 自2025年6月起选用 OpenAI 产品，将 ChatGPT 与 Codex 用于房源出租流程和环境风险评估。

具体内容

OpenAI 官方发布案例称，欧洲住宅房地产运营商 Heimstaden 自2025年6月起选用 OpenAI 产品，将 ChatGPT 与 Codex 用于房源出租流程和环境风险评估。发布方自述，荷兰市场虚拟布置房源图片成本从约50欧元降至不足0.10欧元，降幅超99%；一名无软件开发背景的可持续性分析师用 Codex 评估20112项资产，生成超600万行数据，预计交付需求从5人一年缩减为2人两个月；ChatGPT Enterprise 上线后2至3个月内员工采用率达50%。这些成效均为发布方自述，未经独立验证。

  • 发布方称荷兰虚拟布置房源图片成本由约50欧元降至不足0.10欧元，降幅超99%
  • 无开发背景的分析师用 Codex 评估20112项资产，交付需求从5人一年缩至2人两个月
  • ChatGPT Enterprise 上线后2至3个月内员工采用率达50%，员工仍负责审核与批准

依据官方原始发布整理；案例成效为发布方自述。
