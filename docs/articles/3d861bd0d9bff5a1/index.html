Codex 中的智能体技能（Agent skills）

Codex 宣布支持“智能体技能”：可复用的指令包，可附带脚本与资源，帮助 Codex 可靠完成特定任务。

具体内容

Codex 宣布支持“智能体技能”：可复用的指令包，可附带脚本与资源，帮助 Codex 可靠完成特定任务。技能在 Codex CLI 和 IDE 扩展中均可用，用户可输入 `$skill-name` 显式调用，也可由 Codex 根据提示自动选择。技能遵循 agentskills.io 的开放规范，以包含必需 `SKILL.md` 的文件夹形式组织，可按用户安装于 `~/.codex/skills` 或按仓库安装于 `.codex/skills`，并附带若干内置与精选技能。

  • 技能是可复用指令包，可含脚本与资源
  • 支持 `$skill-name` 显式调用或由 Codex 自动选择
  • 遵循 agentskills.io 规范，按用户或按仓库安装
