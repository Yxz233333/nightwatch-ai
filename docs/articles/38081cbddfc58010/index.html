NVIDIA 宣布，航空航天与汽车领域的领先企业正采用 NVIDIA DoMINO NIM 微服务（属于 NVIDIA PhysicsNeMo AI 物理框架）加速工程设计流程。通过整合 GPU 加速计算、PhysicsNeMo 与交互式数字孪生技术，企业将建模与仿真工作流提速至传统方法的 500 倍，从而加快创新。该消息来自官方发布记录，具体范围以原文为准。

  • 企业使用 DoMINO NIM 微服务加速航空航天与汽车设计。
  • 整合 GPU 加速、PhysicsNeMo 和数字孪生技术。
  • 官方称建模与仿真工作流较传统方法提速最高 500 倍。
