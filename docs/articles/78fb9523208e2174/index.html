NVIDIA 发布 Rubin HPC——加速科学、工程与分析智能体的新 GPU

NVIDIA 在 SC26 上宣布推出 Vera Rubin 平台中的新 GPU Rubin HPC，面向科学、工程与分析工作负载的仿真和数据处理。

具体内容

NVIDIA 在 SC26 上宣布推出 Vera Rubin 平台中的新 GPU Rubin HPC，面向科学、工程与分析工作负载的仿真和数据处理。原文称其单 GPU 拥有超过 5 万个 CUDA 核心，并配备稀疏数据加速能力与第七代 NVLink 互连，强调计算与数据搬运均衡设计，以加速稀疏矩阵、模板计算、排序归约等常见模式，配合 CUDA-X 库缩短智能体“假设—仿真—修正”循环。该产品预计 2028 年可用。

  • 单 GPU CUDA 核心数超过 5 万个，原文称其为创纪录水平。
  • 采用稀疏数据加速与第七代 NVLink，强调计算与数据搬运均衡。
  • 面向科学工程仿真与数据分析，配合 CUDA-X 库服务智能体工作流。
