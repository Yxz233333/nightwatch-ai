Codex 更新：更丰富的上下文、目标模式、浏览器改进与锁定后远程使用

OpenAI 发布 Codex 系列功能更新。

具体内容

OpenAI 发布 Codex 系列功能更新。macOS 版 Codex 应用新增 Appshots，可用快捷键把某个应用窗口连同截图和可用文本附加到对话线程，让 Codex 无需冗长提示即可理解用户当前所看内容。目标模式已在 Codex 应用、IDE 扩展和 CLI 全面可用，用户可定义目标与成功标准，让 Codex 持续朝其推进。应用内浏览器标注支持更精细的样式反馈，面向浏览器与前端工作。符合条件的 Mac Computer Use 用户可在 Mac 锁定后继续远程使用 Codex，但受既有区域限制约束。浏览器使用还改进了高级标注模式、资源提取速度、只读 JavaScript 上下文、标签分组与扩展标签杂乱问题及可靠性。

  • Appshots 用快捷键把应用窗口截图与文本附加到 Codex 线程，减少设置提示。
  • 目标模式在应用、IDE 扩展和 CLI 全面可用，可设定结果与成功标准。
  • 锁定后计算机使用让符合条件的 Mac 用户远程继续工作，受区域限制。
