该版本更新日志显示，Codex CLI 0.161.0 将 GPT-6.1 Sol 设为内置与 Amazon Bedrock 目录的默认模型，并在 Bedrock 上支持多智能体 V2 与 Ultra 推理。新增终端内 MCP 登录、语音设备选择及 Daybreak 可选启用等能力，同时修复文件系统提权、Windows 终端会话、输入提交与重试回退等问题。

  • GPT-6.1 Sol 成为内置与 Bedrock 目录默认模型
  • Bedrock 支持多智能体 V2 与 Ultra 推理
  • 新增 /mcp login 与语音设备本地偏好保存

CLI 稳定版本；桌面端功能另以对应公告为准。
