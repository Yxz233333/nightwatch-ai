首份Anthropic Public Record调查结果

Anthropic开展名为Anthropic Public Record的全国调查，了解公众对AI的态度。

具体内容

Anthropic开展名为Anthropic Public Record的全国调查，了解公众对AI的态度。首轮于2025年11月至12月进行，覆盖近5.2万名美国人。摘要表示，多数问题上AI未沿党派、地域或教育程度明显分化，公众既期待AI益处又担忧其冲击，并要求开发公司承担责任。最常选的希望是治愈疾病（48%），最常见担忧是失业（64%），其次是认知依赖（56%）和虚假信息（52%）。该调查将定期重复，未来计划扩展至美国以外。

  • 首轮调查于2025年11月至12月覆盖近5.2万名美国人，样本经加权处理。
  • 48%受访者将治愈疾病列入前三项希望，64%担忧AI导致失业。
  • 调查显示多数议题上党派、地域和教育差异不明显，分歧多在观点强度。
