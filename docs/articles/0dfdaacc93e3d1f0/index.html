OpenAI 前沿模型和 Codex 现已在 AWS 上可用

具体内容

OpenAI 的前沿模型和 Codex 现已在 AWS 上全面可用，为企业提供通过现有 AWS 环境、控制和采购流程构建 OpenAI 应用的新途径。客户可以开始使用 OpenAI on AWS，并加速从评估到生产的过渡。此举旨在降低企业采用 OpenAI 技术的门槛，利用 AWS 广泛的基础设施和企业服务，使企业能够更便捷地集成和部署 OpenAI 模型。

  • OpenAI 前沿模型和 Codex 在 AWS 上全面可用，企业可通过现有 AWS 流程采购。
  • 客户可利用 AWS 环境、控制和采购工作流构建 OpenAI 应用。
  • 该合作旨在加速企业从评估到生产的过渡。
