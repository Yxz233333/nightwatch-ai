Codex CLI 0.151.0 发布

Codex CLI 发布 0.151.0 稳定版本。

具体内容

Codex CLI 发布 0.151.0 稳定版本。新功能包括：为可选 MCP 服务器发现工具增加可配置宽限期；扩展可在 MCP 工具结果进入模型前检查或替换；插件目录合并各仓库配置并报告无效项目市场。修复涉及 TUI 权限配置保留、切换或回退模型时工具可用性与推理强度、远程沙箱路径语义、MCP 结构化错误保留及子代理令牌计入根目标预算等。

  • 可选 MCP 服务器工具发现增加可配置宽限期
  • 扩展可在结果进入模型前检查或替换 MCP 工具结果
  • 修复切换模型时工具可用性与推理强度错误
  • 远程沙箱按执行器实际主目录与路径约定执行

CLI 稳定版本；桌面端功能另以对应公告为准。
