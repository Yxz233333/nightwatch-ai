Codex CLI 0.121.0 是命令行工具的稳定版本更新。

具体内容

Codex CLI 0.121.0 是命令行工具的稳定版本更新。新增 codex marketplace add 命令，支持从 GitHub、git URL、本地目录和 marketplace.json 地址安装插件市场；TUI 提示历史加入 Ctrl+R 反向搜索；新增内存模式控制与 MCP/插件支持扩展。修复了 macOS 沙箱私有 DNS 处理、Windows 路径匹配、速率限制账户处理等问题，并加固供应链与 CI 输入。桌面端功能以对应公告为准。

  • 新增 codex marketplace add，支持从 GitHub、git URL、本地目录等安装插件市场。
  • TUI 提示历史加入 Ctrl+R 反向搜索，并支持本地召回已接受的斜杠命令。
  • 修复 macOS 沙箱私有 DNS、Windows 路径匹配及速率限制账户处理等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
