具体内容

Codex CLI发布0.99.0稳定版本，新增多项功能：直接运行shell命令不再中断进行中的回合，且可在回合活跃时并发执行；新增/statusline命令用于交互式配置TUI页脚元数据；TUI恢复选择器可按创建时间或最后更新时间切换排序；app-server客户端获得转向活跃回合、列出实验性功能、恢复智能体及选择退出特定通知的专用API；企业/管理员要求可通过requirements.toml限制网络搜索模式并定义网络约束。此外还修复了Windows启动、MCP服务器启动失败、文件监视器误报等问题。

  • 直接shell命令不再中断进行中的回合，并可在回合活跃时并发执行。
  • 新增/statusline命令，可交互式配置TUI页脚显示的元数据。
  • 企业/管理员可通过requirements.toml限制网络搜索模式并定义网络约束。

CLI 稳定版本；桌面端功能另以对应公告为准。
