Codex CLI 0.140.0 发布，新增 /usage 用量视图、/goal 保留超大文本与图片附件、codex delete 等永久删除会话方式、从 Claude Code 选择性导入的 /import、@ 统一提及菜单，以及 Amazon Bedrock API 密钥认证和本地凭据加密存储。修复涉及 SQLite 状态库自动恢复、/review 崩溃、MCP 启动重试与 OAuth 凭据报告等。该版本为 CLI 稳定版，桌面端功能以对应公告为准。

  • 新增 /usage 用量视图、/goal 保留大文本与图片、永久删除会话及 /import 导入功能。
  • 输入 @ 默认打开文件、插件与技能的统一提及菜单。
  • 修复 SQLite 状态库损坏自动恢复、/review 崩溃及 MCP 启动重试等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
