网页版ChatGPT支持对话分支

ChatGPT网页版新增对话分支功能，用户可在不丢失原始对话线程的情况下探索不同方向。

具体内容

ChatGPT网页版新增对话分支功能，用户可在不丢失原始对话线程的情况下探索不同方向。操作方式为将鼠标悬停在某条消息上，点击“更多操作”（⋯），选择“在新聊天中分支”，即可从该点开始一段独立对话。官方称该功能即日起面向所有已登录的网页版用户开放。材料未提及其他平台的支持情况。

  • 网页版ChatGPT可对任意消息创建分支对话。
  • 操作路径为悬停消息后点击更多操作并选择分支。
  • 该功能即日起面向所有已登录网页版用户开放。
