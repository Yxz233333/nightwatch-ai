Codex CLI 0.117.0发布，主要更新包括：插件成为一等工作流，支持启动时同步产品级插件、在/plugins中浏览及安装移除；子代理使用可读路径地址并支持结构化消息；/title终端标题选择器在经典TUI和应用服务器TUI中可用；应用服务器客户端可发送shell命令、监视文件系统变化并连接远程WebSocket。此外修复了TUI重复输出、登录浏览器打开等问题。

  • 插件成为一等工作流，支持启动同步、浏览和安装移除。
  • 子代理采用可读路径地址，支持结构化代理间消息。
  • 应用服务器客户端新增shell命令、文件监视和远程WebSocket连接。

CLI 稳定版本；桌面端功能另以对应公告为准。
