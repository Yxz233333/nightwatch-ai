哈佛物理教授Matthew Schwartz以导师身份，让Claude Opus 4.5在两周内完成一项量子色动力学研究计算，全程不亲自操作文件。他刻意选择“二年级研究生式”课题——重整C参数分布中Sudakov肩部的预言，因为这类问题方法已确立、答案可逐步核查。作者称直接给前沿模型下提示均告失败，于是尝试用一组提示像指导研究生那样引导模型，考察能否产出高质量物理论文。摘要表示这属于中间步骤实验，尚非端到端自主科研。
