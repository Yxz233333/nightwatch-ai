Codex CLI 0.96.0 稳定版发布。

具体内容

Codex CLI 0.96.0 稳定版发布。新功能包括 v2 app-server API 新增异步 thread/compact 触发、websocket 侧通过 codex.rate_limits 事件发出速率限制信号、在全部非 Windows 平台启用 unified_exec，以及约束需求值附带来源信息。修复涉及 TUI 输入浮层 Esc 行为、线程列表优先查询状态数据库、动态工具注入单事务化等，并迁移状态数据库为版本化文件名。

  • v2 app-server API 新增异步 thread/compact 触发 RPC
  • 新增 codex.rate_limits websocket 事件，并在非 Windows 平台启用 unified_exec
  • 线程列表优先查询状态数据库，动态工具注入改为单事务

CLI 稳定版本；桌面端功能另以对应公告为准。
