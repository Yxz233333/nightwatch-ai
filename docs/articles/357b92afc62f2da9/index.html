Codex CLI 发布 0.123.0 稳定版本，新增内置 amazon-bedrock 模型提供商并支持配置 AWS 配置文件，加入 /mcp verbose 诊断命令，改进插件 MCP 加载与实时交接机制。同时修复回滚后 /copy 复制内容、手动 shell 命令期间排队输入、VS Code WSL 终端 Unicode 输入等问题，并更新捆绑模型元数据。

  • 新增内置 amazon-bedrock 模型提供商，支持配置 AWS 配置文件。
  • 新增 /mcp verbose 提供完整 MCP 服务器诊断、资源与模板信息。
  • 修复回滚后 /copy 复制旧响应、shell 命令期间输入卡住等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
