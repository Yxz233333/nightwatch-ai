Anthropic 研究所正式成立

Anthropic 宣布成立 The Anthropic Institute，旨在应对强大AI将给社会带来的重大挑战。

具体内容

Anthropic 宣布成立 The Anthropic Institute，旨在应对强大AI将给社会带来的重大挑战。该研究所由联合创始人 Jack Clark 领导，整合前沿红队、社会影响与经济研究三个团队，并孵化预测AI进展、研究AI与法律系统互动等新方向。其称将利用前沿AI构建者独有的信息，与外部受众合作，同时扩大公共政策团队并开设华盛顿办公室。

  • 研究所由联合创始人 Jack Clark 领导，整合前沿红队、社会影响与经济研究团队。
  • 将孵化AI进展预测及AI与法律系统互动等新研究，并与外部受众合作。
  • Anthropic 同步扩大公共政策团队，并计划春季在华盛顿开设首个办公室。
