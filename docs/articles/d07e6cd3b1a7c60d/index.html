Claude 现已在 Microsoft Foundry 和 Microsoft 365 Copilot 中可用

具体内容

微软与 Anthropic 扩大合作，Claude Sonnet 4.5、Haiku 4.5 和 Opus 4.1 现已在 Microsoft Foundry 公开预览，Azure 客户可构建生产应用和企业智能体。开发者还可结合 Claude Code 使用这些模型。此外，Claude 已集成到 Microsoft 365 Copilot 的 Researcher 智能体和 Copilot Studio，Excel 的 Agent Mode 也新增预览选项以使用 Claude 构建和编辑电子表格。

  • Claude 三款模型在 Microsoft Foundry 公开预览，支持无服务器部署。
  • Claude 已集成到 Microsoft 365 Copilot 的 Researcher 和 Copilot Studio。
  • Excel Agent Mode 新增预览选项，可用 Claude 生成公式、分析数据等。
