Codex CLI 0.80.0 发布

Codex CLI发布0.80.0稳定版本，更新涵盖新功能、缺陷修复与文档。

具体内容

Codex CLI发布0.80.0稳定版本，更新涵盖新功能、缺陷修复与文档。新功能包括在协议与应用服务器中加入会话/线程分叉端点、通过requirement/list暴露requirements.toml、引入指标能力、新增提权沙箱引导及/elevate-sandbox命令，并支持v2 API显式调用技能。修复方面恢复了子进程对LD_LIBRARY_PATH等环境变量的继承，解决GPU相关性能回退，并修正/review命令、补丁审批与Windows粘贴等问题。

  • 新增会话/线程分叉端点，客户端可将会话分支为新线程。
  • 修复子进程未继承LD_LIBRARY_PATH等环境变量导致的性能回退问题。
  • 新增提权沙箱引导与/elevate-sandbox命令，并引入指标能力。

CLI 稳定版本；桌面端功能另以对应公告为准。
