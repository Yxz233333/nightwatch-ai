ChatGPT Work 和 Codex 中的 Data 插件

具体内容

官方推出 Data 插件，帮助用户在 ChatGPT Work 和 Codex 中分析已连接的业务数据。用户可以提出业务问题、调查数据变化，或创建交互式仪表板与报告，并通过后续提问细化分析，还可引入团队的指标定义和其他业务背景。使用前需从插件目录安装 Data，然后通过 @Data 开始对话。连接数据源可能需要设置或授权，查询使用所连接账户的现有权限。

  • Data 插件用于在 ChatGPT Work 和 Codex 中分析已连接的业务数据。
  • 支持提问、调查变化、创建交互式仪表板或报告，并可后续追问细化。
  • 安装后通过 @Data 对话，查询沿用所连接账户的现有权限。
