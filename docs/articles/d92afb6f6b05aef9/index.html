Codex 云端支持 GitLab（Beta）

Codex 云端新增 GitLab 支持，目前处于 Beta 阶段，适用于所有 ChatGPT 套餐。

具体内容

Codex 云端新增 GitLab 支持，目前处于 Beta 阶段，适用于所有 ChatGPT 套餐。用户可将 GitLab 项目连接到 Codex 云端并创建环境，通过 `@codex` 从 issue 或合并请求启动任务，也可请求一次性或自动的合并请求审查。该集成运行在 Codex 云端，工作区管理员可禁用连接器；GitLab 自托管或 Dedicated 版本需管理员配置连接，且 webhook 活动要求 GitLab 19.0 及以上。当 GitLab 省略折叠或超大 diff 时，Codex 无法完成审查。

  • Beta 阶段覆盖所有 ChatGPT 套餐，集成运行于 Codex 云端。
  • 可用 `@codex` 从 issue 或合并请求启动任务并请求审查。
  • 自托管/Dedicated 需管理员配置，webhook 要求 GitLab 19.0+。
