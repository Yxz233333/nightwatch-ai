该官方发布称，Xcode 26.3原生集成Claude Agent SDK，即驱动Claude Code的同一底层框架，开发者可在Xcode内使用子智能体、后台任务和插件，让Claude自主处理更复杂、运行时间更长的编码任务。此前Xcode 26已支持Claude Sonnet 4，但仅限逐轮请求。Xcode 26.3以发布候选版向Apple开发者计划成员提供，并称将很快上架App Store。
