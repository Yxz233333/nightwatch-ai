NVIDIA Agent Toolkit 扩展，将企业智能体扎根于公司数据

NVIDIA 官方博客介绍 Agent Toolkit 的扩展内容：新增 Agent Knowledge Foundation，结合 CUDA-X 库与 Auto-Ontology，把企业原始数据映射为业务概念；并纳入 Nemotron Retriever、Kumo 系列开放模型、OpenShell 安全运行时与 NemoClaw 蓝图。

具体内容

NVIDIA 官方博客介绍 Agent Toolkit 的扩展内容：新增 Agent Knowledge Foundation，结合 CUDA-X 库与 Auto-Ontology，把企业原始数据映射为业务概念；并纳入 Nemotron Retriever、Kumo 系列开放模型、OpenShell 安全运行时与 NemoClaw 蓝图。文章称企业可在不迁移数据、不改动既有工作流与治理控制的前提下使用该基础。文中还列举 Palantir、Databricks、Snowflake、SAP、ServiceNow、Zoom 等合作方场景，属官方发布信息，非独立验证。

  • Agent Knowledge Foundation 含 CUDA-X 库与 Auto-Ontology，可将原始数据映射为业务概念
  • 配套 Nemotron Retriever、Kumo 系列开放模型及 OpenShell 安全运行时
  • 官方称企业无需迁移数据或改动治理控制即可使用
