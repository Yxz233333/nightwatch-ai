Codex CLI 发布 0.84.0 稳定版本。

具体内容

Codex CLI 发布 0.84.0 稳定版本。本次更新在 Rust 协议与类型中为文本元素增加额外元数据，以支持更丰富的客户端渲染和模式演进；同时将发布构建任务超时从 30 分钟提高到 60 分钟，以缓解 Rust 发布流水线（尤其是 Windows 上）的不稳定问题。桌面端功能以对应公告为准。

  • Rust 协议与类型新增文本元素元数据，支持更丰富渲染
  • 发布构建超时由 30 分钟延长至 60 分钟
  • 旨在减少 Rust 发布流水线的不稳定问题

CLI 稳定版本；桌面端功能另以对应公告为准。
