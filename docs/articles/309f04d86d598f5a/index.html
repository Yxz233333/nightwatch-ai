具体内容

Anthropic 与合成、计算和分析化学家合作提升 Claude 的化学能力，并发布首份白皮书，聚焦化学家最常见的分析输入——NMR 谱图。稿件称，团队从模型训练截止后发表的 ChemRxiv 预印本中选取 20 个化合物，比较 Claude Opus 4.7、Opus 4.6、Sonnet 4.6 与 ChemDraw、MestReNova 的谱图预测表现，并测试 Claude 由实验谱图反推结构的能力。作者强调这只是初步进展，未消除化学数据长期存在的问题。

  • 测试集取自模型训练截止后发表的预印本，共 20 个化合物，覆盖四类 NMR 挑战。
  • 氢谱上 Opus 4.7 平均误差约 ±0.079 ppm，作者称低于常用容差窗口。
  • 碳谱上 Opus 4.7 与 MestReNova 接近持平，作者称 Claude 还能从谱图反推结构。
