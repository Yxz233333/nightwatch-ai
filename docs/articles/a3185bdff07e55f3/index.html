ChatGPT 开始逐步推出锁定聊天：选定对话仍保存在账户中，但从常规历史、置顶与搜索中隐藏。用户通过四位账户 PIN 或支持的设备身份验证打开。该功能面向 Free、Go、Plus 和 Pro 用户分批开放，覆盖网页、移动端及新版桌面应用；数据保留和模型改进设置不因此改变。

  • 在对话的更多菜单中选择锁定聊天。
  • 锁定影响常规入口中的可见性，打开时需要账户 PIN 或支持的设备验证。
  • 这是分批推出的功能更新，不能保证全部账户立即可用。
