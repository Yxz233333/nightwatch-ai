具体内容

Hugging Face 博文介绍“决策模型”这一新接口：输入状态与若干带类型的问题，模型不生成文本，而是直接对预设选项打分并返回概率分布。文章以客服工单分流为例，演示 choice、score、noul 三种原语，并说明 Transformers 新增 DecisionPipeline、AutoModelForDecision 与 /v1/systemone 端点，llama.cpp 也支持同一接口，Hub 提供专用标签，可用 Trainer 微调。作者强调其价值在于把决策与概率作为一等输出，而非发明分类本身。

  • 决策模型接收状态与问题，返回带类型的决策及概率，不逐词生成文本。
  • 提供 choice、score、noul 三种原语，分别对应选项分布、有序评分与是/否概率。
  • Transformers 与 llama.cpp 均支持 /v1/systemone 接口，Hub 设专用标签便于发现模型。
