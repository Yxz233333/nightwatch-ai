NVIDIA RTX Spark 紧凑型台式机现已上市

NVIDIA 宣布，ASUS、Dell 和 MSI 的 RTX Spark 紧凑型台式机已开售，Acer、GIGABYTE、HP 与 Microsoft 的产品将陆续推出。

具体内容

NVIDIA 宣布，ASUS、Dell 和 MSI 的 RTX Spark 紧凑型台式机已开售，Acer、GIGABYTE、HP 与 Microsoft 的产品将陆续推出。原文称这些机型搭载 20 核 Grace CPU、Blackwell RTX GPU 与最高 128GB 统一内存，面向本地 AI 智能体、图像视频生成和模型微调，并配套 Adobe、Blender、ComfyUI 等软件更新。原文还提到 Windows Server 2028 将支持 DGX Station for Windows。

  • ASUS、Dell、MSI 的 RTX Spark 紧凑型台式机已开售，更多厂商机型将陆续推出。
  • 原文称其最高配 128GB 统一内存，可本地运行 1200 亿参数大模型。
  • 文章同时介绍Adobe、Blender 5.3及ComfyUI生态进展；其中部分功能已先行可用，不全是当日新增。
