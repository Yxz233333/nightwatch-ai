该文介绍 Elith 与 NVIDIA 发布的 Nemotron-Personas-Finance-Japan，这是开源人物画像数据集 Nemotron-Personas-Japan 的金融领域扩展。作者称其为首个百万记录规模、将日本官方统计与家庭金融及金融素养数据配对的开源人物画像数据集。数据基于政府官方统计，用 NeMo SDG-PGMs 与 NeMo Data Designer 生成，并参考日本多家金融机构和行业协会的反馈设计。数据集含 900 万人物画像、每条 50 个字段，以 CC BY 4.0 许可发布，可用于商业用途，面向对话代理、客户模拟与模型评估等金融 AI 开发场景。

  • 作者称这是首个百万记录级、结合日本官方统计与家庭金融数据的开源人物画像数据集。
  • 数据集含 900 万人物画像，每条 50 个字段，以自然日语书写，采用 CC BY 4.0 许可。
  • 生成使用 NeMo SDG-PGMs 与 NeMo Data Designer，并参考日本金融机构与行业协会反馈。
