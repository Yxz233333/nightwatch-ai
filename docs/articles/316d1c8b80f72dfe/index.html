我们如何为ChatGPT构建兼顾用户信任与相关性的全新广告系统

OpenAI工程团队撰文介绍ChatGPT广告投放系统的设计思路。

具体内容

OpenAI工程团队撰文介绍ChatGPT广告投放系统的设计思路。文章指出，传统广告系统依赖搜索词或页面浏览等离散意图事件，而ChatGPT中的用户意图跨多轮对话逐步形成，有时并不存在合适的广告时机。为此团队构建了一套定制广告投放系统，基于经后训练的前沿大模型，通过工具调用完成广告检索、排序、相关性评估以及竞价与定价。文章还涉及对话记忆不影响回答、编排器在智能体循环中调用广告工具、候选过滤与最终资格检查等环节。

  • 广告系统基于经后训练的前沿大模型，通过工具调用完成检索、排序、相关性评估与竞价
  • 设计强调对话记忆不用于影响ChatGPT的回答内容
  • 针对意图跨多轮对话演变的场景，设置候选过滤与最终资格检查等环节

依据官方原始发布整理；测试、预览及未来计划不等于已全面上线。
