具体内容

Codex CLI 发布 0.56.0 稳定版本，本次更新引入更紧凑、成本更低的 GPT-5-Codex-Mini 模型选项，并合并多项修复与功能改进。更新涉及应用服务器 v2 命名空间与通知、TypeScript SDK 新增 modelReasoningEffort 选项、TUI 组件重构、对话历史文件目录调整、令牌刷新处理改进，以及 Windows 沙箱目录警告等。这些改动主要面向命令行工具与 IDE 扩展的使用体验和稳定性。

  • 引入 GPT-5-Codex-Mini，定位为更紧凑、成本更低的模型选项
  • 应用服务器新增 v2 命名空间、通知及 Thread/Turn 等 API
  • TypeScript SDK 增加 modelReasoningEffort 选项，TUI 组件重构

CLI 稳定版本；桌面端功能另以对应公告为准。
