加强 ChatGPT 在敏感对话中的回应能力

OpenAI 宣布与 170 多位心理健康专家合作，改进 ChatGPT 在敏感对话中的表现。

具体内容

OpenAI 宣布与 170 多位心理健康专家合作，改进 ChatGPT 在敏感对话中的表现。官方摘要称，改进后的模型能更好地识别用户痛苦情绪、以共情方式回应，并引导用户寻求现实世界支持，同时将不安全回应减少了最多 80%。该工作旨在让 ChatGPT 在敏感时刻更安全、更具支持性。具体评估方法和适用范围需以原始发布为准。

  • 官方称不安全回应最多减少 80%，并增强共情与转介支持。
  • 改进聚焦识别痛苦情绪并引导用户获取现实帮助。
