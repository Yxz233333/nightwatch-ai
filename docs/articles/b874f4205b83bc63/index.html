筹备下一轮安全冲刺，加固 OpenAI 系统

OpenAI 官方发布称，正筹备下一轮内部安全冲刺，将引入新研究人员与外部安全伙伴，与自家团队一起用其模型测试并加固系统。

具体内容

OpenAI 官方发布称，正筹备下一轮内部安全冲刺，将引入新研究人员与外部安全伙伴，与自家团队一起用其模型测试并加固系统。此次与安全公司 Cathedral 合作，由对方研究人员借助 OpenAI 模型挑战其防御。OpenAI 同时表示将扩大漏洞赏金计划，相关奖励区间中点将平均增至原来的四倍以上，并公开上一轮冲刺的经验。发布方称上轮曾投入 25% 产品工程师，用 Codex 调查发现、在隔离环境复现漏洞并准备补丁。相关成效均为发布方自述。

  • OpenAI 计划开展下一轮内部安全冲刺，联合外部安全伙伴用自家模型测试防御。
  • 与 Cathedral 合作，由其研究人员借助 OpenAI 模型寻找系统弱点。
  • 漏洞赏金计划扩容，关键发现奖励提高逾三倍，并公开上轮经验。
