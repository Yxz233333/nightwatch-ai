Anthropic 与美国能源部（DOE）宣布多年期合作，作为 Genesis Mission 的一部分，聚焦美国能源主导、生物与生命科学、科研生产力三个领域，可能影响全部 17 个国家实验室的工作。Anthropic 计划向 DOE 研究人员提供 Claude 及工程师团队开发专用工具。文中提到此前与 DOE 的合作包括与国家核安全管理局共同开发核风险分类器，以及在劳伦斯利弗莫尔国家实验室部署 Claude。

  • 合作聚焦能源主导、生物与生命科学、科研生产力三个领域
  • 计划向 DOE 研究人员提供 Claude 与工程师团队开发的专用工具
  • 此前合作包括核风险分类器与劳伦斯利弗莫尔实验室部署 Claude
