该版本为CLI稳定版更新。

具体内容

该版本为CLI稳定版更新。新功能包括：macOS上可用codex app启动Codex桌面端并在缺失时自动下载DMG；支持从~/.agents/skills加载个人技能并兼容旧路径，新增列出和下载公共远程技能的API与事件；/plan支持内联提示参数和粘贴图片；Shell相关工具可并行执行；Shell执行可获取CODEX_THREAD_ID；Linux沙箱引入Bubblewrap与FFI接线。修复涉及Git命令审批、线程列表、沙箱模式、中断后挂起、审查模式审批事件和401错误诊断等。

  • macOS新增codex app启动桌面端，缺失时自动下载DMG
  • 支持从~/.agents/skills加载个人技能，并新增公共远程技能列表与下载API
  • 修复Git命令绕过审批、codex exec中断后挂起及401错误诊断等问题

CLI 稳定版本；桌面端功能另以对应公告为准。
