Codex 在 CLI 与 IDE 扩展中为本地任务默认开启网页搜索。默认使用由 OpenAI 维护的网页结果索引缓存模式，返回预索引结果而非实时抓取页面；实时模式则获取最新网页数据。使用 --yolo 或其他完全访问沙箱设置时，搜索默认切换为实时结果。用户可通过 web_search 配置项在 cached、live、disabled 三种模式间切换或关闭该工具。

  • Codex CLI 与 IDE 扩展的本地任务默认启用网页搜索。
  • 默认 cached 模式返回预索引结果，live 模式抓取最新数据。
  • 完全访问沙箱下默认 live，可用 web_search 配置切换或禁用。
