Codex CLI 0.81.0 发布

Codex CLI 发布 0.81.0 稳定版本。

具体内容

Codex CLI 发布 0.81.0 稳定版本。默认 API 模型切换为 gpt-5.2-codex；codex mcp-server 的 codex 工具在响应中加入 threadId，以配合 codex-reply 工具；无头运行自动改用设备码登录；Linux 沙箱支持只读挂载路径；TUI 支持部分工具调用渲染。此外修复了 Zellij 回滚、Windows 不安全命令提示、配置解析错误上报等问题，并新增 config.toml 的 JSON Schema 文档与 Bazel 构建支持。

  • 默认 API 模型切换为 gpt-5.2-codex
  • MCP 服务响应加入 threadId，支持 codex-reply
  • Linux 沙箱支持只读挂载，无头运行自动设备码登录

CLI 稳定版本；桌面端功能另以对应公告为准。
