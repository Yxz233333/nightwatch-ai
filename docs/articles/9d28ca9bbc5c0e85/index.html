更精准地绘制全球森林：Canopy Height Maps v2 发布

Meta 与世界资源研究所合作发布开源模型 Canopy Height Maps v2（CHMv2）及其全球尺度树冠高度地图。

具体内容

Meta 与世界资源研究所合作发布开源模型 Canopy Height Maps v2（CHMv2）及其全球尺度树冠高度地图。该模型以 Meta 自监督视觉模型 DINOv3 为核心，并在大规模卫星影像数据集 SAT-493M 上预训练，通过阴影、纹理和树冠形状等视觉线索估计树高，无需大量人工标注。官方称相比 2024 年发布的初版，新版本在精度、细节和全球一致性上明显提升，R² 从 0.53 升至 0.86，并减少了对高大树木的偏差。该地图可用于监测森林健康、追踪恢复进展、识别退化与估算碳储量。

  • CHMv2 以 DINOv3 为骨干，在 SAT-493M 卫星影像上预训练，利用阴影、纹理等线索估计树冠高度。
  • 官方称模型 R² 由 0.53 提升至 0.86，并减少对高大树木的预测偏差。
  • 训练数据新增地理分布更多样的高质量激光雷达样本，并配套自动匹配工具与专用损失函数。
