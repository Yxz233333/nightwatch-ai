社会科学研究中的编程智能体

该文基于2026年初对1260名定量社会科学家的基线调查，考察编程智能体在研究中的使用情况。

具体内容

该文基于2026年初对1260名定量社会科学家的基线调查，考察编程智能体在研究中的使用情况。摘要表示，81%的受访者用过生成式AI辅助研究，但仅20%每周多次使用命令行编程智能体，其中Claude Code最常见。使用率在学科、职业阶段、性别和院校类型间差异明显，作者强调样本非代表性、组间比较仅为描述性，不能解读为因果。

  • 81%受访者用过生成式AI，仅20%定期使用编程智能体
  • Claude Code最常用，86%的编程智能体用户报告使用
  • 使用率在学科、职业阶段、性别与院校类型间差异显著
