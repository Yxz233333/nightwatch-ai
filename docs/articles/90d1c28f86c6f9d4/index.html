该新闻称Anthropic将在三年内向联邦“Genesis Mission”计划投入1.5亿美元，用于加速AI驱动的科学与技术发现。资金将让Claude面向NASA、NIH、NSF等超过15个参与机构开放。Anthropic此前已与DOE合作将Claude引入国家实验室，并推出Claude Science、学术席位及AI for Science等项目。原文未说明各机构具体使用方式或效果。

  • Anthropic三年投入1.5亿美元支持Genesis Mission。
  • 资金用于向NASA、NIH、NSF等超15个机构提供Claude。
  • 此前已与DOE合作将Claude引入国家实验室。
