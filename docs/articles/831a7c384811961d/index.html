扩大 Skala 的获取渠道，为预测性 DFT 开辟更快路径

具体内容

微软研究院发布博客，介绍其深度学习交换关联泛函 Skala 的进展：Skala 1.1 训练数据量为此前公开版本的 2.5 倍，在 GMTKN55 基准的 55 个子集中有 32 个取得最低误差，加权平均误差为 2.8 kcal/mol，作者声称其精度超过当前领先的全局（范围分离）杂化泛函，同时保持半局域泛函的计算成本。博客还宣布 Skala 已集成进 CP2K，并正在接入 Psi4、FHI-aims、ORCA 和 VASP，同时推出持续更新的性能基准。上述结果来自微软研究院自述，本次整理未额外核验独立复现情况。

  • Skala 1.1 训练数据为此前版本的 2.5 倍，在 GMTKN55 的 55 个子集中 32 个误差最低。
  • 作者称其加权平均误差 2.8 kcal/mol，精度超过领先杂化泛函而成本相当于 meta-GGA。
  • Skala 已进入 CP2K，并正集成到 Psi4、FHI-aims、ORCA 与 VASP。
