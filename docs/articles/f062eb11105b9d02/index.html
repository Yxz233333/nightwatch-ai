Codex CLI 0.52.0 发布

据官方发布记录，Codex CLI 0.52.0 为稳定版本更新。

具体内容

据官方发布记录，Codex CLI 0.52.0 为稳定版本更新。亮点包括 TUI 改进：流式输出时可见排队消息、Windows 自动模式指引、撤销操作、压缩提示可配置；图像方面支持客户端缩放、通过 MIME 校验防止崩溃并重新启用 SDK 图像转发测试；支持以“!”直接执行命令，并可购买额度以增加用量。其他改进涉及新的 CLI 认证存储抽象与 keyring 支持、app-server 的会话摘要 RPC、事件流与对话管理优化等。桌面端功能以对应公告为准。

  • TUI 支持流式时显示排队消息、撤销操作与可配置压缩提示
  • 图像支持客户端缩放与 MIME 校验，重新启用 SDK 图像转发测试
  • 新增认证存储抽象与 keyring 支持，并支持购买额度增加用量

CLI 稳定版本；桌面端功能另以对应公告为准。
