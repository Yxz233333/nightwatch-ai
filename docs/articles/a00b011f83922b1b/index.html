NVIDIA 与 AWS 扩展全栈合作，提供面向未来创新的安全高性能计算平台

在 AWS re:Invent 上，NVIDIA 与 Amazon Web Services 宣布扩展战略合作，新增覆盖互连技术、云基础设施、开放模型和物理 AI 的技术集成。

具体内容

在 AWS re:Invent 上，NVIDIA 与 Amazon Web Services 宣布扩展战略合作，新增覆盖互连技术、云基础设施、开放模型和物理 AI 的技术集成。作为扩展的一部分，AWS 将支持 NVIDIA NVLink Fusion——一个用于自定义 AI 基础设施的平台——以部署其自研芯片，包括下一代 Trainium4 芯片。原文摘要在此处截断，未提供更多合作细节、时间表或性能数据。

  • NVIDIA 与 AWS 在 re:Invent 上宣布扩展战略合作，覆盖互连、云基础设施、开放模型和物理 AI。
  • AWS 将支持 NVIDIA NVLink Fusion 平台，用于部署包括下一代 Trainium4 在内的自研芯片。
