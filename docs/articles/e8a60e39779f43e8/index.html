该发布列出 Codex CLI 0.42.0 的主要变更：引入基于 Rust SDK 的实验性 MCP 客户端，新增 responses-api-proxy 组件，加入 CODEX_SECURE_MODE=1 安全模式以限制进程可观测性，并让 codex exec 事件更明确。此外还包含危险命令检查、Windows 安全处理、/status 改版、无分页会话列表等体验改进，以及多项稳定性修复和内部重构。

  • 引入实验性 Rust SDK MCP 客户端与 responses-api-proxy
  • 新增 CODEX_SECURE_MODE=1 限制进程可观测性
  • codex exec 事件更明确并加强危险命令检查

CLI 稳定版本；桌面端功能另以对应公告为准。
