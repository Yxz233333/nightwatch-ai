这是 Codex CLI 的 0.142.5 版本更新公告，属于稳定版本的功能修复。本次更新主要解决一个日志安全问题：此前完整的 Responses WebSocket 请求负载可能被写入追踪日志，新版本已阻止这一行为。该修复通过 #30771 回移植到 0.142 发布分支。公告未涉及桌面端功能，相关变化以对应公告为准。

  • 修复完整 Responses WebSocket 请求负载被写入追踪日志的问题。
  • 修复以 #30771 回移植至 release/0.142 分支。
  • 本次为 CLI 稳定版本更新，桌面端功能另见对应公告。
