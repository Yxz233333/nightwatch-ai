OpenAI o3与GPT-4.5将退役

据官方发布记录，OpenAI将继续在ChatGPT中退役使用量有限的旧模型。

具体内容

据官方发布记录，OpenAI将继续在ChatGPT中退役使用量有限的旧模型。o3将在90天过渡期后于2026年8月26日从ChatGPT退役，GPT-4.5将在30天过渡期后于2026年6月26日退役。两者目前仅通过模型设置向付费用户提供。官方明确这些变更仅适用于ChatGPT，API不受影响。

  • o3将于2026年8月26日从ChatGPT退役，过渡期90天
  • GPT-4.5将于2026年6月26日退役，过渡期30天
  • 变更仅适用于ChatGPT，API不受影响
