该版本更新日志显示，Codex CLI 0.102.0 主要围绕权限与审批体验改进：新增更统一的权限流程、TUI中的权限历史，以及在被阻止目录上授予沙箱读权限的斜杠命令；网络审批提示中展示更丰富的主机与协议信息。此外还加入可配置的多智能体角色、模型重路由通知，并修复远程图片附件持久化、屏幕阅读器动画门控、线程恢复语义及 js_repl 稳定性等问题。

  • 新增统一权限流程与权限历史，并支持斜杠命令授予沙箱读权限
  • 网络审批提示展示更丰富的主机与协议上下文
  • 新增可配置多智能体角色与 model/rerouted 重路由通知

CLI 稳定版本；桌面端功能另以对应公告为准。
