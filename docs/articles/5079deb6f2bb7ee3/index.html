具体内容

Codex CLI 0.115.0 发布，新增多项功能：支持模型通过 view_image 和 codex.emitImage 请求全分辨率图像检查；js_repl 暴露 codex.cwd 和 codex.homeDir 并在单元格间保留工具引用；实时 websocket 会话增加转录模式和 v2 交接支持；v2 应用服务器暴露文件系统 RPC 并新增 Python SDK；智能审批可通过守护子代理路由请求；应用集成使用 Responses API 工具搜索流程。同时修复了子代理沙箱继承、js_repl 挂起、TUI 退出卡顿等问题。

  • 支持全分辨率图像检查，提升精确视觉任务能力。
  • 新增实时转录模式、v2 交接及文件系统 RPC 和 Python SDK。
  • 修复子代理沙箱继承、js_repl 挂起和 TUI 退出卡顿等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
