Swiss AI 发布 Apertus 1.5 技术说明，介绍8B和70B模型新增图像与音频理解、可选思考模式、工具使用改进及262144 token上下文。本文是10月15日发布的说明，权重已于7月24日以 Apache 2.0 许可发布，并非10月新发布的权重。语音处理在原文中仍标为实验性。

  • 8B及70B权重沿用 Apache 2.0 许可，提供训练与数据透明度资料。
  • 上下文窗口扩大至262144 token，支持图像与音频输入。
  • 技术说明日期与模型权重发布时间分开记录，实验性能力不视为成熟服务。

官方已发布信息；评测及性能数据为发布方报告，适用条件以原文为准。
