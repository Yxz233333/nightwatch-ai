扩展 Project Glasswing

Anthropic 宣布将 Project Glasswing 扩展至超过 15 个国家的约 150 个新组织。

具体内容

Anthropic 宣布将 Project Glasswing 扩展至超过 15 个国家的约 150 个新组织。该项目旨在保障全球重要软件安全，初始约 50 个合作伙伴使用 Claude Mythos Preview 扫描代码库，已发现超过 10,000 个高危或严重安全漏洞。新成员需满足安全要求，涵盖电力、水务、医疗、通信和硬件等行业。Anthropic 还发布 Claude Security 产品，并计划进一步扩展项目及网络验证计划。
