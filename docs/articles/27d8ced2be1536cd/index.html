Anthropic 推出 Cyber Mission 网络安全计划

Anthropic 宣布启动 Anthropic Cyber Mission，长期致力于帮助防御者保护关键系统和软件。

具体内容

Anthropic 宣布启动 Anthropic Cyber Mission，长期致力于帮助防御者保护关键系统和软件。计划从两个领域起步：应对前沿模型被滥用于漏洞利用和网络操作，以及支持关键基础设施和开源软件的安全。具体举措包括将 Project Glasswing 并入 Cyber Verification Program、推出关键基础设施防御计划，并与埃森哲、CrowdStrike、Palo Alto Networks 等创始伙伴合作。此外还推出 OSS Scanner 为开源项目提供免费模型扫描报告。

  • 启动 Cyber Mission，聚焦防御者工具、研究与资源。
  • 推出关键基础设施防御计划，创始伙伴包括 CrowdStrike 等。
  • OSS Scanner 为登记开源项目提供免费模型扫描报告。
