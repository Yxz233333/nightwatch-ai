  • npm发布流程改用可信发布，但修复要到0.38.0才生效。
  • 新增审批与回合结束通知，并恢复预发布逻辑。
  • 合并多项依赖升级与权限、审查模式相关修复。

CLI 稳定版本；桌面端功能另以对应公告为准。
