Anthropic 发布 Claude Opus 4.8，称其在编码、智能体任务和专业工作方面表现更强，并能更一致地处理长时间运行的任务。该版本与 claude.ai 的任务努力程度控制、Claude Code 的动态工作流以及更便宜的快速模式一同推出。作者声称 Opus 4.8 在诚实性方面有显著改进，更可能标记不确定性，减少无依据声明。定价与 Opus 4.7 相同。

  • Opus 4.8 在编码、智能体任务和专业工作上表现更强。
  • claude.ai 用户可控制 Claude 在任务上投入的努力程度。
  • 作者称 Opus 4.8 约比前代少四倍概率忽略代码缺陷。
