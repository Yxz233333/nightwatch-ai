在ChatGPT插件中连接多个账户

OpenAI宣布ChatGPT插件现可连接多个账户，支持范围不再局限于Gmail、Google日历和Google联系人。

具体内容

OpenAI宣布ChatGPT插件现可连接多个账户，支持范围不再局限于Gmail、Google日历和Google联系人。用户可把个人账户与工作账户带入同一段对话，让ChatGPT跨个人和工作账户查找信息并协助完成任务。该功能面向所有ChatGPT套餐，覆盖网页、移动端和桌面端。

  • ChatGPT插件支持连接多个账户，范围超出Gmail、日历和联系人。
  • 个人与工作账户可在同一对话中使用，便于跨账户查找信息。
  • 该功能面向所有ChatGPT套餐，覆盖网页、移动端和桌面端。
