Codex Remote 正式可用（26.623）

官方公告称 Codex Remote 已达到正式可用（GA）。

具体内容

官方公告称 Codex Remote 已达到正式可用（GA）。用户可通过 ChatGPT 移动应用在已连接的 Mac 或 Windows 主机上开始或继续工作，查看进度并在手机上批准操作。远程控制改为每台 iOS 或 Android 设备与每台主机之间经过认证的一对一二维码配对；2026 年 6 月 8 日以来使用过的连接保持配对，更早的非活跃连接需重新配对。新增 DigitalOcean 插件可让 Codex 创建 Droplet、配置 SSH 访问并作为远程工作区接入。公告还列出断线重连恢复、连接后消息输入框恢复、截图时浏览器闪烁减少等改进。

  • Codex Remote 正式可用，可从手机端操作已连接主机。
  • 远程控制改为设备与主机间一对一认证二维码配对。
  • 新增 DigitalOcean 插件，可创建 Droplet 并接入为远程工作区。
