Codex CLI 发布 0.144.5 版本，属于缺陷修复更新。

具体内容

Codex CLI 发布 0.144.5 版本，属于缺陷修复更新。该版本改进了危险命令检测，覆盖更多强制形式的 rm 命令，并在命令被拒绝时给出更清晰的拒绝原因。更新记录仅列出这一项修复及其提交编号，未涉及其他功能变化。

  • 改进危险命令检测，覆盖更多强制 rm 形式。
  • 命令被拒绝时提供更清晰的拒绝原因。
  • 该版本为 CLI 稳定版，桌面端功能另见公告。
