GPT-6.1 Terra 开始向 ChatGPT Work 与 Codex 推出

OpenAI 发布 GPT-6.1 Terra，强调视觉推理、电脑操作与自然写作中的效率，并开始在 ChatGPT Work、Codex 及 API 提供。

具体内容

OpenAI 发布 GPT-6.1 Terra，强调视觉推理、电脑操作与自然写作中的效率，并开始在 ChatGPT Work、Codex 及 API 提供。

  • 可用范围取决于订阅、地区和工作区设置；逐步推出不等于所有用户立即可用。
  • API 模型标识为 gpt-6.1-terra；普通调用价格每百万输入、缓存输入、输出 token 分别为1、0.05、5美元。
  • 帮助中心说明整体套餐限制不变；模型效率提升不等于提高套餐总额度。

官方已发布并逐步推出；具体可用性以账号及工作区设置为准。
