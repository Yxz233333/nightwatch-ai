该更新介绍 ChatGPT 桌面应用在浏览、代码审查和生成图像编辑方面的改进。内置浏览器支持地址栏访问历史记录、搜索 Google，并可在设置中管理历史；Chrome 扩展支持提及打开的标签页、引入高亮文本、就 YouTube 视频提问以及右键调用 ChatGPT。多文件夹项目可跨仓库查看改动并统一审查差异；生成图像可在扩展查看器中切换 Focused 与 Canvas 视图并发送定向编辑。

  • Chrome 扩展可提及标签页、引入高亮文本并就视频提问
  • 多仓库项目可统一查看改动并审查差异
