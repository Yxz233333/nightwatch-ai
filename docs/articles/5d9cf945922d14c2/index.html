Codex CLI发布0.142.0稳定版本，新增/usage查看和兑换用量重置额度、/plugins按来源分类远程插件并推荐安装、可配置的token预算跟踪与耗尽中止、多代理委派模式配置、索引式网页搜索模式以及定时提醒和当前时间查询等功能。同时修复了Linux TUI恢复渲染、执行服务器断线重连、远程环境路径保留、插件加载安装、子代理错误上报和线程持久化等问题，并优化了启动延迟和日志量。

  • 新增/usage兑换用量重置额度、/plugins分类推荐插件及可配置token预算跟踪。
  • 支持多代理委派模式配置、索引式网页搜索和定时提醒与时间查询。
  • 修复Linux TUI恢复、断线重连、插件加载等问题并降低启动延迟。

CLI 稳定版本；桌面端功能另以对应公告为准。
