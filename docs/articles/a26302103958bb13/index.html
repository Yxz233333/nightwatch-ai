该功能更新说明，ChatGPT Work 与 Codex 现可在桌面应用内置浏览器中直接调用受支持网站提供的工具，无需单独建立连接，ChatGPT 可自行发现任务所需工具。用户点击地址栏箭头即可查看当前页面提供的工具。原文指出，网站工具基于 WebMCP，需要受支持的账户、模型和网页，且仅在桌面内置浏览器中可用，不通过 Chrome 扩展提供；原有的网站访问与敏感操作确认机制仍然适用。

  • ChatGPT Work 与 Codex 可在桌面内置浏览器中直接使用网站提供的工具。
  • 网站工具基于 WebMCP，需受支持的账户、模型和网页。
  • 该能力不通过 Chrome 扩展提供，原有访问与敏感操作确认仍适用。
