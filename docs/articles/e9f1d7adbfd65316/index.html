Codex CLI 发布 0.89.0 版本更新。

具体内容

Codex CLI 发布 0.89.0 版本更新。新增 /permissions 命令并提供更精简的审批集合，同时保留 /approvals 以兼容旧用法；新增 /skill 界面，可单独启用或禁用技能；斜杠命令选择改为优先精确匹配和前缀匹配。应用服务器支持 thread/read 与归档线程过滤，客户端支持分层 config.toml 解析。修复波浪号展开可能逃逸 HOME 的问题，并调整 TUI 计时逻辑。

  • 新增 /permissions 命令，提供更短审批集合并保留 /approvals 兼容
  • 新增 /skill 界面，可单独启用或禁用技能
  • 应用服务器支持 thread/read 及归档线程过滤

CLI 稳定版本；桌面端功能另以对应公告为准。
