Claude 现已在 Xcode 中正式可用

Anthropic 宣布开发者可将 Claude 账户连接至苹果 Xcode 26，使用 Claude Sonnet 4 驱动的编码智能功能。

具体内容

Anthropic 宣布开发者可将 Claude 账户连接至苹果 Xcode 26，使用 Claude Sonnet 4 驱动的编码智能功能。该集成允许开发者在工作流中直接调用 Claude 的编码能力，以加速苹果平台应用开发。Claude 订阅用量限额跨平台共享，Xcode 中可用部分额度。该功能适用于包含 Claude Code 的 Pro、Max 以及 Team 和 Enterprise 高级席位。原文还提及 Anthropic 向 METR 提供类似员工权限以评估系统安全，并与新加坡政府签署备忘录。

  • 开发者可将 Claude 账户连接 Xcode 26，使用 Claude Sonnet 4 的编码智能功能。
  • Claude 订阅用量限额跨平台共享，Xcode 中可用部分额度。
  • 支持含 Claude Code 的 Pro、Max 及 Team/Enterprise 高级席位。
