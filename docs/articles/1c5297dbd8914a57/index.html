Anthropic向Public First Action捐赠2000万美元

Anthropic宣布向Public First Action捐赠2000万美元，该组织是关注公共利益AI议题的501(c)(4)机构。

具体内容

Anthropic宣布向Public First Action捐赠2000万美元，该组织是关注公共利益AI议题的501(c)(4)机构。Anthropic称AI将带来巨大益处，但也伴随滥用和失控等风险，未来几年的AI政策决策将触及公共生活几乎所有方面。公司希望参与政策制定，支持灵活监管以获取AI益处、控制风险并保持美国领先。Public First Action由共和党和民主党策略师共同创立领导，致力于跨党派支持AI治理政策。Anthropic表示有效治理意味着对包括自身在内的公司更多审查。

  • Anthropic向Public First Action捐赠2000万美元，该组织为501(c)(4)机构。
  • Public First Action由两党策略师共同创立，旨在推动AI治理政策。
  • Anthropic称有效AI治理意味着对包括自身在内的公司更多审查。
