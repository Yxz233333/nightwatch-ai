Anthropic 员工让 Claude 尝试黎曼猜想未果，但一个未发布的研究版 Claude 在相关问题上改进了黎曼 zeta 函数满足猜想的零点比例下界，从 41.6% 提高到 67.2%。原文称该结果借鉴了数学家数十年研究和 Bombieri 2000 年论文，由 Anthropic 两位数学家研究验证，并生成可形式化验证的证明；外部专家 Brian Conrey 与 Dan Goldston 也审阅了论文。Anthropic 表示不预期这些技术能证明黎曼猜想，但视其为 AI 数学能力进展的例证。

  • 未发布研究版 Claude 将 zeta 函数零点比例下界从 41.6% 提升至 67.2%。
  • 结果由 Anthropic 数学家验证，并生成 Lean 形式化证明通过 comparator 校验。
  • Anthropic 称不预期该技术路线能直接证明黎曼猜想。
