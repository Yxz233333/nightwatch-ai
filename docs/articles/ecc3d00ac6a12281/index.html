具体内容

Anthropic 宣布投资500亿美元，与 Fluidstack 合作在得克萨斯州和纽约州建设数据中心，未来还将有更多站点。设施为 Anthropic 定制，以优化其工作负载效率，支持前沿研发。项目预计创造约800个永久岗位和2400个建筑岗位，站点将在2026年陆续上线。Anthropic 称此举有助于满足超30万企业客户对 Claude 的需求，并配合美国 AI 行动计划。

  • Anthropic 与 Fluidstack 合作在得州和纽约州建设定制数据中心。
  • 项目投资500亿美元，预计创造约800个永久和2400个建筑岗位。
  • 站点将于2026年陆续上线，支持前沿研发和 Claude 企业需求。
