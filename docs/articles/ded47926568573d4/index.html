具体内容

Codex CLI 0.98.0 稳定版发布，引入 GPT-5.3-Codex，并将 Steer 模式设为默认稳定功能：运行任务时 Enter 立即发送，Tab 显式排队后续输入。修复了 TypeScript SDK 中 resumeThread() 参数顺序、切换或恢复模型时的指令处理、远程压缩不一致及登录后云要求重载等问题。还恢复了默认助手人格为 Pragmatic，并统一了协作模式命名。

  • 引入 GPT-5.3-Codex，Steer 模式稳定并默认启用。
  • 修复 resumeThread() 参数顺序及模型切换指令处理问题。
  • 恢复默认助手人格为 Pragmatic，统一协作模式命名。

CLI 稳定版本；桌面端功能另以对应公告为准。
