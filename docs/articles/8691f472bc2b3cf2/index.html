GPT-5.4 与 GPT-5.4 mini 将于 8 月 31 日从 Codex 退役

该官方公告称，2026 年 8 月 31 日起，使用 ChatGPT 账号登录的用户将无法在 Codex 中使用 GPT-5.4 与 GPT-5.4 mini；这两个模型仍可在 OpenAI API 以及使用 API 密钥认证的 Codex 会话中使用。

具体内容

该官方公告称，2026 年 8 月 31 日起，使用 ChatGPT 账号登录的用户将无法在 Codex 中使用 GPT-5.4 与 GPT-5.4 mini；这两个模型仍可在 OpenAI API 以及使用 API 密钥认证的 Codex 会话中使用。公告建议分别替换为 GPT-5.6 Terra 与 GPT-5.6 Luna，并提醒在截止日期前更新工作区默认设置、已保存的模型设置、托管配置、自定义智能体与定时任务。

  • 2026 年 8 月 31 日起 ChatGPT 登录用户在 Codex 中不可用。
  • API 及 API 密钥认证的 Codex 会话仍可继续使用。
  • 建议分别替换为 GPT-5.6 Terra 与 GPT-5.6 Luna。
