Gemini API 推出工具检索功能

Google发布Gemini API Tool Retrieval预览，在Interactions API中为大量工具提供按需检索，适用于Gemini 3.6及后续模型，包括Gemini 4。

具体内容

Google发布Gemini API Tool Retrieval预览，在Interactions API中为大量工具提供按需检索，适用于Gemini 3.6及后续模型，包括Gemini 4。

  • 通过tool_search及defer_loading按需加载工具参数模式；服务端与客户端自建检索是两种模式。
  • 模型可先看到工具名称与描述，需要时检索参数；支持远程MCP。
  • token与延迟收益取决于工具模式实际加载比例，应按自己的流量评估，不保证所有请求都更快。
