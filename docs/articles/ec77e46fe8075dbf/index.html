Gemini Omni 1.2 Flash：更快、更具成本效益，支持更长片段

谷歌DeepMind发布Gemini Omni 1.2 Flash视频生成模型，原生支持最长15秒片段，可按1秒步长指定3至15秒时长。相比1.1版本，价格下调30%，720p视频为每秒0.07美元；增强参考图遵循能力，人物、产品与品牌元素在多角度和转场中更一致；支持多轮对话式编辑，可逐轮替换产品或背景而无需重新生成。该模型已在Gemini API和Google Cloud正式可用，并介绍Flow、Google Vids、Gemini应用和Google Ads等产品入口；Gemini应用向AI Ultra订阅者逐步推出，Vids免费使用需符合Google账号或Workspace条件。

  • 原生支持最长15秒视频，可按1秒步长指定3至15秒时长。
  • 价格较1.1版本下调30%，720p视频为每秒0.07美元。
  • 支持多轮对话式编辑，可逐轮替换产品或背景而无需重新生成。

API等入口正式可用；Gemini应用仍按AI Ultra资格逐步推出。
