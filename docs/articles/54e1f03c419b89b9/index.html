Codex Remote 正式可用与 DigitalOcean 插件

官方公告称 Codex Remote 现已在所有 ChatGPT 套餐中正式可用。

具体内容

官方公告称 Codex Remote 现已在所有 ChatGPT 套餐中正式可用。用户可从 ChatGPT 移动应用在已连接的 Mac 或 Windows 主机上开始或继续工作、查看进度并在手机上批准操作。远程控制采用每台受支持移动设备与每台主机之间经过认证的一对一二维码配对；6 月 8 日以来使用过的连接保持配对，更早的非活跃连接需重新配对；退出登录会关闭远程控制但不移除已有配对。新增 DigitalOcean Droplet Workspace 插件可创建 Droplet、配置 SSH 访问并接入 Codex 应用作为远程工作区，连接前需更新移动端与应用至最新版本。

  • Codex Remote 面向所有 ChatGPT 套餐正式可用。
  • 退出登录关闭远程控制但保留已有配对。
  • DigitalOcean 插件可创建 Droplet 并配置 SSH 接入。
