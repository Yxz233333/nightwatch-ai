  • SimReady 资产按 Profile、Feature、Requirement 三级规范校验关节驱动等仿真设置。
  • 流程包括下载资产、组装机械臂与夹爪、检查关节与接触，再运行抓取放置。
  • 示例采用固定起点、无视觉和脚本化抓取，未验证真实硬件部署，不能据仿真结果保证实机效果。
