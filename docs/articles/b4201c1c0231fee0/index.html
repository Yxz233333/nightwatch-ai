Box、Dropbox 和 SharePoint 现已接入 Library

ChatGPT Library 在原有 Google Drive 基础上新增 Box、Dropbox 和 SharePoint。

具体内容

ChatGPT Library 在原有 Google Drive 基础上新增 Box、Dropbox 和 SharePoint。连接后用户可浏览和搜索文件与文件夹，并通过 Add from Library 或 @mentions 将所需文件加入对话，无需重复上传。用户可在对话旁查看支持的文件预览并追溯引用来源，也可让 ChatGPT 对文件进行总结、分析、比较或创作，或选定文件夹跨文件处理。官方称该集成正向多个用户层级在网页版 Chat 和 Work 中推出，移动端支持稍后跟进，现有文件权限和工作区控制仍然适用。

  • Box、Dropbox、SharePoint 加入 ChatGPT Library，与 Google Drive 并列。
  • 可通过 Add from Library 或 @mentions 添加文件，无需再次上传。
  • 支持文件预览、引用追溯及跨文件夹处理，移动端支持稍后跟进。
