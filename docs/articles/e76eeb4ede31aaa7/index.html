ChatGPT 与 Codex 中的 Zendesk 和 OneNote 插件（Beta）

该条目为功能更新。

具体内容

该条目为功能更新。官方表示在插件目录中新增 Zendesk 与 OneNote 两个插件，均处于 Beta 阶段。Zendesk 插件帮助团队在 ChatGPT 和 Codex 中查看支持工单与客户历史、查找相关知识并准备回复，成员需连接自己的 Zendesk 账户，仅能处理其有权访问的支持信息。OneNote 插件用于查找和总结笔记、汇总决策与行动项，并通过受支持的操作创建或更新笔记。材料未说明可用地区与套餐范围。

  • 插件目录新增 Zendesk 与 OneNote 插件，标注为 Beta
  • Zendesk 插件需成员连接本人账户，仅访问其有权信息
  • OneNote 插件支持查找总结笔记及创建更新笔记
