Anthropic 承诺投入 1000 万美元支持加拿大 AI 研究

具体内容

Anthropic 宣布向加拿大研究机构投入 1000 万加元，资助有益且负责任的 AI 应用研究，并公布与 Amii、Mila、Vector 三家区域 AI 研究所以及多家医院和高校的合作。公司还发布首份基于 Anthropic Economic Index 的加拿大国别简报，称加拿大在 Claude.ai 使用量上全球第八。此外，今年夏季将把三家研究所纳入 Anthropic for Startups 计划，相关初创企业各获至少 5000 美元 API 额度。

  • 与 Amii、Mila、Vector 及多家医院高校建立合作
