Codex CLI 0.31.0 发布，新增在声明 MCP 服务器时配置 startup_timeout_ms 选项的支持，官方称这是社区高度需求的功能，尤其受 Windows 用户关注。该版本还改进了 MCP 服务器初始化错误处理与容错，修复 macOS 上使用 ctrl+v 从 Finder 粘贴图片的问题，并包含会话级 token 用量与上下文信息、/status 显示 CLI 版本等多项合并改动。

  • 新增 MCP 服务器级 startup_timeout_ms 启动超时配置
  • 改进 MCP 初始化错误处理与容错，修复 macOS 粘贴图片问题
  • token 用量与上下文信息移至会话层级，/status 显示 CLI 版本

CLI 稳定版本；桌面端功能另以对应公告为准。
