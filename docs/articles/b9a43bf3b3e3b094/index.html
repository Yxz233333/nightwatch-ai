Hugging Face 与 OpenRouter 联手，让开放权重模型更易运行

Hugging Face 宣布与 OpenRouter 合作，将 Inference Providers 的请求路由从自研路由器切换为 OpenRouter 的路由器。

具体内容

Hugging Face 宣布与 OpenRouter 合作，将 Inference Providers 的请求路由从自研路由器切换为 OpenRouter 的路由器。作者称，Hub 上由服务商提供的开放权重模型，现在可用 Hugging Face 令牌通过同一 API 调用，路由器会依据实时价格、速度和可靠性为每次请求选择服务商，失败时自动重试其他服务商。文章还给出 OpenRouter 统计的开放权重模型用量与价格对比，并说明图像、视频、音频生成仍走原有通道，自定义服务商密钥对语言模型不再可用。

  • 语言模型请求改由 OpenRouter 路由，按实时价格、速度、可靠性选服务商并在失败时重试。
  • 支持 OpenAI Chat Completions、Responses 与 Anthropic Messages API，代码无需改动。
  • 可在模型 id 后加 :fastest、:cheapest 或服务商名指定策略，也可在设置中禁用服务商。
