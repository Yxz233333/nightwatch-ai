具体内容

Codex CLI 0.165.0 正式版加入内置 Google Cloud Vertex AI 提供商和 GPT-6.1 Terra 模型目录，并改善会话导航、推理设置及记忆。

  • 可用 model_provider = "gcp" 配置内置 Vertex AI 提供商；线程附属分叉仍属实验性 app-server API。
  • 新增会话仓库过滤、目录分组；支持的模型默认允许在对话中修改推理强度，新配置默认采用 memory v2。
  • 修复审批审阅器默认值、MCP 请求取消、中断后代理消息唤醒、模型不存在时重试及市场 URL 验证等问题。

已发布正式版；其中个别 API 明确标为实验性。
