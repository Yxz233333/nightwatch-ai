费加罗集团与OpenAI合作，将《费加罗报》新闻内容引入ChatGPT

费加罗集团与OpenAI宣布建立合作，使《费加罗报》及关联出版物的新闻报道与档案内容可在ChatGPT中通过摘要和节选形式被发现，并附原文链接，覆盖新闻、商业、文化和生活方式等类别。

具体内容

费加罗集团与OpenAI宣布建立合作，使《费加罗报》及关联出版物的新闻报道与档案内容可在ChatGPT中通过摘要和节选形式被发现，并附原文链接，覆盖新闻、商业、文化和生活方式等类别。费加罗方面表示将保留完整编辑独立性与内容控制权，并计划在多个团队引入ChatGPT Enterprise，按自身AI章程与编辑标准探索更多用途。OpenAI称此举延续其与全球新闻机构合作、提升可靠信息可发现性的方向。

  • 合作覆盖《费加罗报》及关联出版物的当前报道与档案内容，以摘要、节选加原文链接形式呈现。
  • 费加罗集团称将保留完整编辑独立性和对自身新闻内容的控制权。
  • 费加罗计划在多个团队引入ChatGPT Enterprise，并按AI章程探索工作流与读者服务用途。
