Anthropic 宣布 Rahul Patil 加入公司担任首席技术官，负责产品、计算、基础设施、推理、数据科学和安全等工程组织，以扩展 Claude 满足全球企业需求。Patil 拥有超过20年基础设施经验，曾任 Stripe CTO，并在 AWS、微软和 Oracle 云基础设施担任高级工程领导职务。原联合创始人兼 CTO Sam McCandlish 转任首席架构师，专注于大规模模型训练、预训练及研究生产力和强化学习基础设施。Anthropic 称目前服务超过30万企业客户。
