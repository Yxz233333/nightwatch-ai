面向临床医生的ChatGPT医疗公共数据功能

官方发布信息显示，美国符合条件的ChatGPT for Clinicians用户现可使用Healthcare Public Data功能。

具体内容

官方发布信息显示，美国符合条件的ChatGPT for Clinicians用户现可使用Healthcare Public Data功能。该插件整合九个应用，用于检索生物医学研究、临床试验、药物信息、Medicare数据及医疗服务提供者记录等公共医疗来源。用户需从插件目录安装并连接所需应用；这些应用为只读，不访问患者病历，且官方提示不要向公共来源搜索发送受保护健康信息。

  • 插件整合九个应用，覆盖研究、试验、药物与Medicare等公共来源。
  • 应用为只读，不访问患者病历。
  • 官方提示搜索公共来源时勿包含受保护健康信息。
