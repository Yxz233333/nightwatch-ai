埃森哲与 Anthropic 宣布扩大合作，成立埃森哲 Anthropic 业务组，培训约 3 万名专业人员使用 Claude，并推出面向 CIO 的联合产品，以 Claude Code 为核心帮助企业从 AI 试点转向规模化生产。合作初期聚焦金融、生命科学、医疗和公共部门等受监管行业。

  • 成立埃森哲 Anthropic 业务组，约 3 万名专业人员接受 Claude 培训。
  • 推出首个联合产品，以 Claude Code 为核心衡量并推动企业 AI 采用。
  • 初期聚焦金融、生命科学、医疗和公共部门等受监管行业。
