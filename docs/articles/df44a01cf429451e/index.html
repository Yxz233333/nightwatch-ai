Codex CLI 0.133.0 为稳定版本更新。

具体内容

Codex CLI 0.133.0 为稳定版本更新。新特性包括 Goals 默认启用并由专用存储支撑、跨活跃轮次跟踪进度；codex remote-control 改为前台命令运行并报告机器状态；权限配置新增列表 API、继承与 requirements.toml 支持；插件发现与扩展生命周期事件增强。修复涉及 TUI 工作目录、计划模式回车提交、后台终端轮询、AGENTS 指令加载等。桌面端功能以对应公告为准。

  • Goals 默认启用，由专用存储支撑并跨活跃轮次跟踪进度。
  • 权限配置新增列表 API、继承、托管 requirements.toml 与 Windows 沙箱集成。
  • 修复 TUI 复用本地 socket 时选错工作目录、计划模式 Shift+Enter 误提交等问题。

CLI 稳定版本；桌面端功能另以对应公告为准。
