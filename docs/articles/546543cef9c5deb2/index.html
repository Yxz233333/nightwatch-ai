英文原始摘要

We prove that there are absolute constants c > 0 and K0 such that $`W_r(k)\gt k^{ck\lfloor\log_2 r\rfloor}`$ for every $`k\ge K_0`$ and r ≥ 2. Consequently $`W_r(k)^{1/k}\to\infty`$ for each fixed r ≥ 2, giving a quantitative positive resolution of Erdős's superexponential-growth question, including the two-color case.
