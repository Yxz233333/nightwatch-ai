作者发布两个 Swift 包：AnySpeechRecognizer 沿用 Apple SpeechAnalyzer 风格 API，可切换 Apple、NVIDIA Parakeet、阿里 Qwen3-ASR 等识别引擎，并新增基于 Streaming Sortformer 的说话人分离；AnyDecisionModel 以类型化结果和概率回答是非、多选与评分问题，支持 MLX、Core AI、llama.cpp、Jev、Ollama 等后端。两者均可从 Hugging Face Hub 下载开源模型并在设备端运行。作者在 M4 Max 上给出部分词错误率数据，并说明仅测过 macOS 27、未测 iPhone。

  • AnySpeechRecognizer 保留 Apple 语音 API 形态，在共享API代码中可改导入，切换具体引擎还需调整转写器构造。
  • SpeakerDiarizer 跟踪最多四名说话人，配合 SpeakerTimeline 将词与说话人关联。
  • AnyDecisionModel 从模型概率导出答案，提供是非、多选、评分及置信度。

依据原始发布整理；研究和厂商测试不等于独立验证。
