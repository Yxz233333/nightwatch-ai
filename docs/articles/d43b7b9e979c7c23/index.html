Gemini Decisions API：快速、校准的多模态决策

谷歌发布 Gemini Decisions API，由新模型 Gemini Decision 1 驱动，面向工具选择、策略检查、模型路由、上下文评分等封闭集合决策。

具体内容

谷歌发布 Gemini Decisions API，由新模型 Gemini Decision 1 驱动，面向工具选择、策略检查、模型路由、上下文评分等封闭集合决策。官方称可一次传入文本、图像、音频、视频和 PDF（最多 256K token）及最多 1000 个独立问题，模型不逐 token 生成答案，而是单次前向打分，返回概率与置信度，端到端延迟 150-250 毫秒，输入定价每百万 token 0.10 美元、输出不计费。文中还列举 Gemini Notebook 路由、Stitch 设计迭代、CC 表情选择及搜索 MCP 工具安全层等内部用例。

  • 支持是/否、多选（2-255 项）和有序评分三类问题，每个答案附 0 到 1 置信度。
  • 单次请求共享输入只计费一次，问题仅增加自身指令与标准 token，输出 token 不计费。
  • 官方称在代理路由、推理、排序和多模态理解基准上领先，且校准误差最低。
