Codex CLI 0.170.0正式版发布，改进实时语音、遥测鉴权及连接恢复。

  • TUI实时语音通话加入WebRTC协商；OpenTelemetry HTTP导出器支持自动刷新鉴权头。
  • 实验性支持跨环境同名MCP服务器；修复MCP OAuth登录、注销与取消过程的凭据竞争。
  • 超大WebSocket请求可回退HTTP；改善云端会话重连和恢复轮次保留。
  • 修复Windows文件替换、沙箱权限保留和运行时注册，并保持权限更新及子线程原有沙箱限制。

已发布正式版；实验性功能不等于默认启用。
