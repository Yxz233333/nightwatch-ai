具体内容

该版本新增一项功能：支持通过 API 配置 GPT-6-Astra，同时不改变默认模型，也不在模型选择器中显示它。对应改动为将 GPT-6-Astra 模型目录回移至 0.153 分支（#42605）。官方说明该版本为 CLI 稳定版本，桌面端功能以对应公告为准。

  • 新增通过 API 配置 GPT-6-Astra 的能力。
  • 配置后不改变默认模型，也不在模型选择器中显示。
  • 对应改动为将 GPT-6-Astra 模型目录回移至 0.153（#42605）。

CLI 稳定版本；桌面端功能另以对应公告为准。
