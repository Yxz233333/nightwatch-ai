Codex CLI 发布 0.40.0 稳定版本。

具体内容

Codex CLI 发布 0.40.0 稳定版本。更新说明显示，默认模型改为 gpt-5-codex，并在达到 220k tokens 时自动触发压缩；/status 中可查看用量限制；新增 /review 命令，可审查指定提交、对比基线分支或按自定义指令审查；MCP 工具调用默认超时为 60 秒，可在 config.toml 中按单个 MCP 服务器设置 tool_timeout_sec 覆盖。此外还包含多项修复与依赖调整。

  • 默认模型改为 gpt-5-codex，达到 220k tokens 时自动触发压缩。
  • 新增 /review 命令，支持审查指定提交、对比基线分支或自定义指令。
  • MCP 工具调用默认超时 60 秒，可按服务器配置 tool_timeout_sec 覆盖。

CLI 稳定版本；桌面端功能另以对应公告为准。
