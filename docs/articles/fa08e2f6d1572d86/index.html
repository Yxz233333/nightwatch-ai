具体内容

Codex CLI 0.57.0发布，重点改进TUI体验和长运行命令超时处理。TUI方面，斜杠命令列表支持ctrl-n/p导航，回溯时跳过/status噪音。合并的PR包括统一exec输出格式、修复apply_patch重命名/移动路径解析、跳过insufficient_quota错误重试、启用统一exec时移除shell工具、为TypeScript SDK增加network_access和web_search选项、WSL更新时规范化Windows路径等。该版本为CLI稳定版，桌面端功能以对应公告为准。

  • TUI支持ctrl-n/p导航斜杠命令列表，回溯跳过/status噪音
  • 改进长运行命令超时处理，跳过insufficient_quota错误重试
  • 修复apply_patch重命名/移动路径解析，WSL更新规范化Windows路径

CLI 稳定版本；桌面端功能另以对应公告为准。
