# 夜行 AI 观察站

主站：https://ai.zmh.icu

公开 AI 阅读站：https://jiankong.ai.zmh.icu

## 网站与账号

主站为本机 Node.js + SQLite 服务，监听 127.0.0.1:8791，经独立 Cloudflare Tunnel 对外提供 HTTPS。首次可直接在网站创建个人账号，密码至少8位。账号创建后关闭首次创建入口，后续通过相同账号登录。密码采用带随机盐的 scrypt 散列，浏览器使用 HttpOnly 会话。数据文件 data/nightwatch.sqlite 不提交 GitHub。

ChatGPT 与 Codex 分功能更新/功能预告；AI资讯分今日推荐/其他内容，其他内容保留行业新闻、模型动态、工具动态；OpenAI论文单列。板块和分类使用独立路径，支持刷新和浏览器前进后退。论文保留英文原题、原始摘要、原文及独立审查状态说明，后续中文解读由每日整理逐步补充。首轮导入不是全部历史资讯的穷尽回溯。

## GPT 阅读入口

公开站由 GitHub Pages 托管，不要求登录。它包括完整内容库，也精准保留用户主动标记。用户同意公开喜欢和想深入了解的标记，不公开账号、密码、会话和监控日志。

- /content.json：全部内容，interest 数组给出标记类型及时间。
- /interests.json：所有已标记条目。
- /likes.json：喜欢。
- /learn.json：想深入了解。
- /chatgpt.json、/codex.json、/news.json、/papers.json：按板块读取。
- /articles/固定编号/：单条 HTML；该路径下 content.json 为单条结构化内容。
- /llms.txt：AI 读取说明。

点赞和取消标记后，后端运行 publish-public.mjs 导出、提交及推送公开快照；每分钟重试同步。GitHub Pages 构建通常需要额外时间，公开页顶部显示最后快照同步时间，不能误称零延迟。电脑关机时主站登录/标记不可用，公开站保留最近已发布快照。

## 更新和维护

每日北京时间08:00由本聊天的“夜行 AI 网站每日更新”自动化负责检索、核实、中文整理及发布。GitHub 不执行资讯采编。仅可信、已核实的未来计划进入功能预告；没有可核实预告时允许为空，不能填充推测。更新 public/content.json 时保留稳定ID和历史条目，原子替换；不要覆盖用户数据库。之后执行 `node publish-public.mjs` 并回读公开站。

不要用 build-initial.py 覆盖已经编辑的内容库；该脚本仅用于首次导入。数学材料来自 OpenAI math 仓库，保留 Apache-2.0 许可证及出处。

start-local.ps1 启动本项目的服务、隧道和独立转接进程；stop-local.ps1 仅停止本项目。reconnect.ps1 只重启本项目的隧道与转接，不停止数据库后端。隧道凭据保留在本机 .cloudflared 目录，ai-tunnel.yml 本机配置已忽略，绝不提交凭据。

## 夜行监控

桌面快捷方式“夜行监控”统一管理荐书与AI服务器。两个服务器独立在后台每5秒检查，公网入口每60秒检查；窗口隐藏也继续监控。点击顶部服务器仅显示已缓存状态，不启动新的检查、不重置计时和日志。荐书的自动重连设置在切换时保留。启停与重连分别按所属服务器执行。

监控源码位于 H:\shichangdiaoyan\sites\reading-preferences\monitor，夜行监控.exe 为正式程序。

## 验证

`node verify-backend.mjs` 使用临时隔离数据库，验证8位密码/7位拒绝、登录权限、标记保存与取消、完整库及兴趣导出、凭据不公开。实际账号由用户自行创建，测试不能使用用户真实账号。

## 浏览与内容字段（2026-10-18 更新）

所有板块默认“最新”：北京时间今天往前一个日历月（月底按上月实际天数截断），支持指定月份、全部月份和日期待核实。每页10条。月份/类别/搜索/页码保存在URL，浏览器刷新、前后退及详情返回保留列表位置。AI资讯有全部/今日推荐/其他内容，并支持资讯类别；论文在月份下按主要学术领域筛选，始终有全部。

详情路径 /articles/稳定ID/；from 参数保存返回列表地址。每条内容有 details.overview、details.keyPoints 和原始来源。论文有 titleZh 中文主标题、titleEn 英文副标题、category 主要领域、subjectDetail 细分领域、abstractEnglish 原始英文摘要。卡片不再显示手稿通用说明、审阅状态或英文摘要，这些在详情内展示。新增条目与08:00每日更新必须同时补齐这些字段，不改稳定ID。

中文翻译与介绍为辅助阅读，来源是原始题目/摘要/已有发布说明，不把模型整理当独立事实核验。领域采用合并后的主要数学学科，必要时增加新类别，避免大量同义细分类别挤满选择框。

## 时间线与推荐规则（最终调整）

“今日推荐”为滚动24小时内发布的消息，优先使用带时区的 publishedAt。只有日期的当日条目标注时间未详；前一天缺少小时的消息不猜造时间混入。recommendedOn不是新闻发布时间。没有消息显示暂无，不重新推荐旧消息补位。

AI重大突破为已有条目的 breakthrough=true、breakthroughField 标记，保留原section与稳定ID，收藏不重复。初始精选研究成果与方法进展，独立验证、预印本和待实验候选等状态必须在详情说明。右上角“新”根据源发布时间最近7天动态计算，超过期限移除，非永久内容字段。

ChatGPT、Codex、AI资讯各增时间线。时间线为连续横向浏览，首批10条，滑到末端按10条追加，末端显示全部记录，不循环、不重复、不用翻页；普通列表继续10条每页。左右按钮每次移动120px，关闭强制吸附，支持触屏、键盘方向键和拖动滑杆。

发布时间行展示“最新 / 10月 / 9月 / 8月 / 选择”（月份按当前北京日期动态滚动）。括号解释不显示。更早月份、全部月份和日期待核实收进同排末尾的选择；类别放第二排按钮，论文类别保留下拉；搜索位于下方。网页每30秒重算时效标记，每60秒检查内容版本，更新时保留当前筛选与时间线位置。

## 历史归档（2025-09-01 起）

历史内容按原始发布日期入档。ChatGPT 官方发布说明、ChatGPT/Codex 桌面与移动端变更日志、Codex GitHub 稳定版及预发布版、OpenAI 官方新闻、Anthropic 新闻与研究、Google DeepMind、Gemini、DeepSeek、Hugging Face、NVIDIA 的可访问归档覆盖到指定起点。新闻归档包含行业、模型及工具动态，历史稿件不因本次整理而进入今日推荐。

这是已核实来源的历史库，不代表全网全部新闻。RSS、新闻页和 GitHub 发布记录的覆盖范围不同；原文失效、获取失败或未列出细节时明确记录，不推测缺失事实。不为论文每个月凑数量，也不把跨学科案例报告当成所有数学问题均已解决。论文补入 First Proof 证明尝试及 2025 年科研合作案例报告，保留原文与审核局限。

采集缓存、原始页面、翻译缓存与核对报告都在被 Git 忽略的 data/。backfill-history.py 合并到 data/history-candidate.json；enrich-content.mjs 支持 NIGHTWATCH_CONTENT_FILE 指向候选文件，仅补充缺失详情，已有分类与编辑结果保留。确认日期、中文、详情、旧编号、来源及月份覆盖后才原子替换主站 content.json，再导出公开站。不要运行首次导入脚本重置内容，也不要修改用户数据库。完整覆盖说明保存在 content.json 的 coverage 字段，并同步公开站。
